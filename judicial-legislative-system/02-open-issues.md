# 미해결 설계 쟁점

아래는 아직 확정되지 않은 쟁점들이다. 이 저장소에서는 임의로 결론을 내리지 않고
논의 상태 그대로 기록만 한다.

## 1. 처분(재판/행정처분) 유형 명명 — 진행 중, 미확정

- 처음엔 전부 "결정"으로 통일하려 했으나 사용자가 기각: "재판의 종류에도
  판결·결정·명령이 있고, 행정에도 심결·재정·재결·심사·심판 등 다양하다 — 그거
  다 쓸 거임."
- **"심판"은 제외 확정** — 헌법재판소 고유 용어라 충돌 회피.
- **"심판"의 재활용 방향(미확정, 다음에 이어갈 부분)**: 사용자가 "심판은 약간
  메타인지 영역에 관해 논의할 수 있도록 하자"고 제안 — 체계 자체를 대상으로 한
  자기점검·자기반성(메타적) 기능의 명칭으로 쓰고 싶어함. 단, "메타인지"라는
  표현 자체는 쓰지 말고 **한자어 기반 전문용어**로, 그러나 **과도하게 어려운
  한자어는 지양**. (다음 대화에서 후보 명칭을 다시 고민해야 함 — 이전에
  자기심판/자성심사/내성적 심사 등을 가안으로 제시했으나 확정 아님.)
- 남은 후보군: 판결(대심적 쟁송) / 결정(신청·절차형) / 명령(약식) /
  재정(조정·중재 성격) / 심의의결(심의체 의사결정 — 사용자가 재검토 후
  "괜찮다"고 확인함) / 재결 / 심결.

## 2. 인용(citation) 형식 — 진행 중, 미확정

- 실제 한국 판례 인용 관행([사건부호]+연도+일련번호+처분유형, 예:
  "2017헌바127 결정")을 참고해 설계 중.
- 초안(재검토 예정, 확정 아님): 사건부호 8개(입/심/재/업/정/리/상/비, 8개
  구성요소 각각에 대응) + 연도 + 일련번호 + 처분유형. 예: "심 2026-3 결정".
- 내부 조항 지시는 뒤에 이어붙임: "심 2026-3 결정 제2장 제1절 제3조".
- 판례변경 인용: "입 2026-5 결정 (입 2026-1 결정 변경)" 식으로 원처분 병기.
- **사용자가 다음에 다시 보자고 한 부분** — 사건부호 체계와 인용 형식 자체를
  재검토 예정.

## 3. 생애주기 절차 (성립→등기→확정→변경→종결→회복→말소) — 진행 중, 핵심 쟁점

판례법 체계로 매핑한 초안(사용자가 대체로 동의, 단 말소/종결 구간은 재작업 필요):

- 성립 = 선고
- 등기 = 공식기록
- 확정 = 불복기간 도과
- 구성/내용수정 = 확정 전에만 가능
- 변경 = 확정 후 "판례변경"으로만 가능
- 종결 = 효력상실(자동실효기간 도래 또는 판례변경)
- 회복 = 예외적 재확립
- 말소 = 절차적 하자로 원천무효

**확정된 것**: 판례변경의 소급효는 **원칙적으로 장래효(ex nunc)** — 예외 인정
여부·요건은 추후 별도 처분에서 정하기로 보류.

**남은 쟁점 (다음 대화에서 이어갈 것, 사용자가 명시적으로 "한번 잘 생각해
보자"고 함)**:

- 말소와 종결의 **존재론적 지위**를 소급효 유무 기준으로 다시 비교·구분할 것.
  - 잠정안: 종결(장래효, ex nunc) = "유효하게 존재했었다"는 사실은 보존,
    후속 처분·신뢰는 불가침. 말소(소급효, ex tunc) = 성립요건 자체의 흠(절차적
    하자)으로 애초부터 없었던 것으로 취급.
  - 사용자 코멘트: "말소는... 글쎄. 소급하는지에 따라 잘 모르겠네. 소급 여부에
    따라 그 무효 시점 같은 걸 바꿔야 할 듯. 종결과의 존재론적 지위도 상대적으로
    잘 비교해서 양쪽 다 내용상 수정이 필요하면 하자" — 즉 위 잠정안이 최종이
    아니고, 두 개념 다 내용 수정이 필요할 수 있다는 전제로 재검토할 것.
