# 미해결 설계 쟁점

아래는 아직 확정되지 않은 쟁점들이다. 이 저장소에서는 임의로 결론을 내리지 않고
논의 상태 그대로 기록만 한다.

## 1. 처분(재판/행정처분) 유형 명명 — 부분 확정

- 처음엔 전부 "결정"으로 통일하려 했으나 사용자가 기각: "재판의 종류에도
  판결·결정·명령이 있고, 행정에도 심결·재정·재결·심사·심판 등 다양하다 — 그거
  다 쓸 거임."
- **"심판"은 제외 확정** — 헌법재판소 고유 용어라 충돌 회피.
- **메타 영역(체계 자체를 대상으로 한 자기점검) 처분유형: "감리(監理)"로 확정**.
  구법 제58조③("자체 평가를 할 때에는 감리를 두어야 한다")에서 이미 쓰인
  단어를 격상시킨 것 — 완전히 새로 만든 말이 아니라 계보가 있는 선택.
  - 자성(自省)/성찰(省察)/내성(內省)/자정(自正)/환류(還流)/자핵(自劾)/
    자검(自檢) 등을 검토했으나 모두 기각하고 감리로 확정.
  - **감리는 다른 처분유형(판결/결정/명령/재정/심의의결/재결/심결)과 병렬적인
    독립 처분유형으로 자리매김한다** — 결정 계열의 하위종(예: "감리결정")이
    아니라, 개별 사건이 아닌 체계 자체를 대상으로 한다는 점에서 명확히 구분된
    제3의 처분유형. (2026-09-09 확정)
- 남은 후보군(그 외 일반 사건용 처분유형, 여전히 배분 방식 미확정): 판결(대심적
  쟁송) / 결정(신청·절차형) / 명령(약식) / 재정(조정·중재 성격) /
  심의의결(심의체 의사결정 — 사용자가 재검토 후 "괜찮다"고 확인함) / 재결 / 심결.

## 2. 인용(citation) 형식 — 확정

실제 한국 판례 인용 관행([사건부호]+연도+일련번호+처분유형, 예: "2017헌바127
결정")과 헌재의 헌가/헌바/헌마식 구분자 관행을 참고해 아래로 확정. (2026-09-09)

**부호 구조: [구성요소 부호 1자] + [개시방식 구분자 1자]**

- 구성요소 부호 8개: 입(사법입법제도) / 심(사심절차) / **회**(재정회계법,
  구 "재"에서 변경 — 아래 변경 사유 참조) / 업(사업규정) / 정(사인정보규제계획)
  / 리(관계심리규칙) / 상(상시상황) / 비(비상계획)
- 개시방식 구분자 3종:
  - **직** — 직권 개시 (주체가 스스로 시작)
  - **청** — 신청·청구로 개시
  - **불** — 불복·항고로 개시 (제44조 결정의 불복 계열)
- 단, **감리**는 성격상 항상 직권적 자기점검이므로 구분자를 붙이지 않고 부호
  단독으로 쓴다.

**일련번호**: 부호(2자, 감리는 1자) 기준 연도별 독립 카운트.

**인용 예시**

- 일반 사건: `심청 2026-3 결정` (사심절차, 신청형, 2026년 3번째)
- 내부 조항 지시: `심청 2026-3 결정 제2장 제1절 제3조`
- 판례변경: `입직 2026-5 결정 (입직 2026-1 결정 변경)`
- 감리: `심 2026-3 감리`

**변경 사유 — "재/재정" 겹침 해소**: 재정회계법의 부호를 원안 "재"로 두면
처분유형 "재정(裁定)"과 한 인용문 안에서 겹쳐("재직 2026-3 재정") 가독성이
떨어졌다. 처분유형 "재정"은 실제 한국 행정 실무 용어(공정위 시정재정, 특허
재정 등)를 그대로 쓴 것이라 바꾸지 않고, 대신 부호 쪽을 "재" → "회"(재정
**회**계법)로 바꿔 해소했다.

**남겨둔 유사 문제 (미해결, 필요시 재검토)**: 부호 "심"(사심절차)도 처분유형
"심결"·"심의의결"과 같은 음절로 시작해 유사한 겹침이 생길 수 있다(예: "심불
2026-3 심결"). 재/재정만큼 심하게 겹치지는 않는다고 보아 이번엔 손대지
않았다.

## 3. 생애주기 절차 (성립→등기→확정→변경→종결→회복→말소) — 진행 중, 핵심 쟁점

판례법 체계로 매핑한 초안(사용자가 대체로 동의, 단 말소/종결 구간은 재작업 필요):

- 성립 = 선고
- 등기 = 공식기록
- 확정 = 불복기간 도과
- 구성/내용수정 = 확정 전에만 가능
- 변경 = 확정 후 "판례변경"으로만 가능
- 종결 = 효력상실(자동실효기간 도래 또는 판례변경)
- 회복 = 예외적 재확립
- 말소 = 절차적 하자로 원천무효

**확정된 것**: 판례변경의 소급효는 **원칙적으로 장래효(ex nunc)** — 예외 인정
여부·요건은 추후 별도 처분에서 정하기로 보류.

**남은 쟁점 (다음 대화에서 이어갈 것, 사용자가 명시적으로 "한번 잘 생각해
보자"고 함)**:

- 말소와 종결의 **존재론적 지위**를 소급효 유무 기준으로 다시 비교·구분할 것.
  - 잠정안: 종결(장래효, ex nunc) = "유효하게 존재했었다"는 사실은 보존,
    후속 처분·신뢰는 불가침. 말소(소급효, ex tunc) = 성립요건 자체의 흠(절차적
    하자)으로 애초부터 없었던 것으로 취급.
  - 사용자 코멘트: "말소는... 글쎄. 소급하는지에 따라 잘 모르겠네. 소급 여부에
    따라 그 무효 시점 같은 걸 바꿔야 할 듯. 종결과의 존재론적 지위도 상대적으로
    잘 비교해서 양쪽 다 내용상 수정이 필요하면 하자" — 즉 위 잠정안이 최종이
    아니고, 두 개념 다 내용 수정이 필요할 수 있다는 전제로 재검토할 것.
