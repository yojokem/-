## 성격 안내

이 폴더는 **설계를 확정하는 곳이 아니라 배경자료를 정리해 두는 곳**이다.
`02-open-issues.md`에 정리된 쟁점들은 아직 사용자 본인의 가치판단(명칭 취향,
소급효 인정 여부 등)이 필요한 상태로 남겨 두었으며, 이 세션에서 임의로 확정하지
않았다. 확정된 내용만 반영한다는 원칙은 Notion 쪽 진행 상황 문서와 동일하게 유지한다.

## 제약사항 (반드시 지킬 것)

- "박순우" 관련 자료는 완전히 무관한 제3자 기록 — 이 작업과 연결짓지 않는다.
- 관계 기반 공유 페이지 잔여 항목(여자친구용 DB, 만다라트 항목, 다현이 프롬프트)은
  논의 목적이 없는 순수 정보성 항목 — 먼저 꺼내지 않는다.
