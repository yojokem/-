# 변경 이력

## 2026-09-09 (10)

- 부호-처분유형 전수 대조 (사용자 요청 "빈틈 점검"):
  - 처분유형 8종 중 "심결"만 어디에도 쓰이지 않은 것을 발견 — 정의를
    확정(당사자간 실질적 다툼을 전제로 한 합의체의 사실심리형 판정,
    특허심판원·공정위 심결 실무 참고). 조문 배정은 이후 다른 구성요소의
    최초 처분 작성 때로 이월.
  - 재결·심결에 괄호 설명이 없던 문서 공백을 채움(재결=불복·이의 재심사).
  - 부호-처분유형 **후행 음절** 겹침 발견: "정"(사인정보규제계획)/결정,
    "리"(관계심리규칙)/감리 — 이번에도 손보기로 하여 "정"→"**규**",
    "리"→"**칙**"으로 변경. 앞서 고친 "재/재정", "심/심결" (선행 음절
    겹침)과 합쳐, 8개 부호·8종 처분유형 사이 겹침이 첫 음절·끝 음절 모두
    사라짐.
- `02-open-issues.md`, `06-audit-log.md` 갱신.

## 2026-09-09 (9)

- 입직 2026-1 감리 후속 grill 4건 처리:
  1. 제7조①에서 확정 전 단계인데 "재확정"(확정 후 전용 개념)을 언급한
     자기모순 발견 — "재확정" 삭제, 조정만 남김.
  2. 제9조(변질)의 "재확정" 용법이 제8조의 좁은 정의와 같은지 불명확 —
     **잠정 처리**: 용어는 "재확정"으로 유지하되, 이 조에 따른 재확정
     발동 시 주체 본인의 명시적 확인을 받도록 절차 추가(제9조② 신설).
     개념 자체(재확정/판례변경/제3의 명칭)는 다음 감리에서 다시 다룸.
  3. "재결"을 항상 구분자 "불"과 짝짓는 일반원칙화는 보류 — 사안마다 판단
     하기로 확인, `02-open-issues.md`에 명문화.
  4. 부호 "심"(사심절차)을 처분유형 "심결"·"심의의결"과의 겹침 해소를 위해
     **"찰"로 변경** — "재/재정" 때와 같은 이유. 이로써 8개 부호·8종
     처분유형 사이에 겹치는 조합이 완전히 사라짐.
- `02-open-issues.md`, `05-founding-disposition-draft.md` 갱신.

## 2026-09-09 (8)

- **입직 2026-1 감리** 개시(체계 자기점검, 처음으로 실제 감리 처분 실행).
  지적사항 4건 반영:
  1. 재확정(제8조)은 등기 경정과 달리 직권 개시만 허용 — 의도적 차별임을
     명문화(제8조⑤ 신설).
  2. 말소(제12조②)의 처분유형을 재결 → **판결**로 재변경 (재결은 "불복
     재심사"라는 어의라 말소의 실질과 안 맞음).
  3. 순수 종결 사유의 성립 여부를 다투는 이의 절차 신설 (제10조⑤,
     재결/불복, 종결일로부터 7일 이내).
  4. 감리의 발동을 **정기(분기별)+수시 병행**으로 확정 (제14조② 신설).
- 지적 2·3의 결과로 "재결"과 "판결"이 각각의 어의(불복 재심사 / 대심적
  쟁송)에 맞게 재배치됨.
- 감리 기록을 `06-audit-log.md`로 신설. `README.md`, `04-next-steps.md`
  갱신.

## 2026-09-09 (7)

- 최초 처분 초안 2차 검토 (grill) 반영, 나머지 항목 마저 확정:
  - 등기 경정(제4조③): 직권뿐 아니라 **객체의 신청으로도 개시 가능**하게
    확장 — 자신의 기초정보 오류는 당사자가 직접 정정 요구할 수 있어야 함.
  - 구성/내용수정(제7조③): 확정 전 예비단계라는 점을 감안해 결정 →
    **명령**으로 하향.
  - 말소(제12조②): 원천무효급 효과의 무게에 맞춰 결정 → **재결**로 격상.
  - 말소상 종결 정정(제10조④): 장래효→소급효 전환은 원인의 존부·중대성을
    다투는 대심적 쟁송에 가깝다고 보아 심결 → **판결**로 변경.
- 이로써 "등기 조정" 한 항목만 잠정안으로 남고 나머지 전 항목 확정.
- `05-founding-disposition-draft.md`, `04-next-steps.md` 4번 갱신.
