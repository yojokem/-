# 인계 문서 (다른 세션용)

작성: 2026-10-14. 이 문서를 읽은 뒤 `prompt/current.md`와 Notion 최신 prompt 블록을 확인하세요. 충돌하면 Notion이 우선입니다. 문서·artifact에는 버전 번호 대신 '현행'과 기준 날짜로 적습니다.

## 1. 현재 상태

- 현행 규칙은 Notion 맨 아래의 가장 최신 prompt 블록입니다(2026-10-14 기준). 최근 개정의 핵심은 내용 정리 탭(전체 내용 정리 탭, 카드 필수 구성, 모의고사 시험 일시·남은 시간, 새 자료 도착 시 재판정, 최근 파일 탐지)입니다. 상세는 `prompt/current.md`의 최신 블록을 보세요.
- 결정 완료(2026-10-14): 이 개정 현행화 승인. '전체 내용 정리'에는 문항 카드를 넣지 않고 각 요약 카드에서 연계 문항으로 이동하는 링크 버튼을 표시합니다.
- 정리장 artifact는 2026-10-14에 현행 규칙으로 갱신했습니다: '전체 내용 정리' 탭, 내용 정리 카드 ⓐ 핵심 요약·ⓑ 표·ⓒ 암기 포인트·ⓓ 헷갈리는 비교·ⓔ 연계 문항·ⓕ 출처, 모의고사 시험 일시(2026-10-14 11:00~13:00, 사용자 캘린더 기준·공지 원문 미확인)와 남은 시간, 머리말 D-day. ⓐ·ⓒ·ⓓ는 표·각주에 있는 말만 재배열한 AI 정리입니다.
- 새 자료 도착 시 재판정(§17 부칙)은 이번에 새 자료가 없어 수행하지 않았습니다.
- 부트스트랩 artifact 본문은 규칙 버전에 묶이지 않고 '가장 최신 블록'을 가리킵니다. 이 repo의 `bootstrap/bootstrap.html`이 발행본과 같습니다.

## 2. 진행 이력 (요약)

- 규칙은 여러 차례 개정됐고, 각 단계의 변경 요약과 복원표는 `prompt/`에 있습니다(블록 머리에 개정 기록이 있음).
- 이전 개정 요약(1): 순차 내려받기(병렬 base64 금지), 목록 요청은 목록과 직접 링크만 답하기, 모호한 요청은 한 번 확인 후 제작, 도판 탐색·크롭 절차, 필기 판독 보완(노란 정답 표시·그림 확인), 내용 정리 탭 각주 규칙.
- 이전 개정 요약(2): 각주 번호는 CSS 위첨자만 사용(유니코드 위첨자와 "(10)" 대체 표기 금지), 번호는 표마다 1부터, 행 연결 실패 시 표 머리 첫 칸에 '표 전체' 각주.
- 정리장 내용: KSH 서술형 도판 7개 내장(KSH-39·41·43은 원본에 그림이 없음), YBL 필기 7개 파일 반영, 블라인드·완전본 짝 확인 10건 반영.
- 2026-10-14에 약물별 총정리 artifact와 23학번 퀴즈 artifact를 새로 만들었습니다. 총정리는 교안 원본 대조(하위 에이전트 4개)로 누락·오류를 보정해 v2까지 발행했습니다.

## 3. 사용자 선호·제약 (반드시 지킬 것)

- 보고는 간결한 한국어, ① / ⓐ / ◦ 목록. 예외·유의사항만 길게. 파일 목록 요청에는 목록과 직접 링크만 답함.
- Notion 블록 삭제는 매번 새 승인 필요. 오래된 구판 블록과 직전 복원표들은 '정리 대기'로 남아 있음. 임의 삭제 금지.
- 규칙 변경은 사용자 승인 후 반영. 단 사용자가 "바로 현행화", "현행직결"이라고 하면 즉시 현행화.
- PR 생성·push는 요청이 있을 때만. 결정이 필요하면 선택지 질의를 사용.
- "블라인드"는 사용자가 export에서 문항을 지운 것. 완전본과 짝지어 보충함.
- 사용자는 세션 전용 md와 '파일 색인' 부트스트랩 기능을 원하지 않음. 핵심 기능은 유지하고 장황해지지 않게.
- 근거 없는 내용은 만들지 말고 '추정'으로 표시(프롬프트 §5·§6).

## 4. 미결 사항

1. KSH-39·41·43 도판: 원본에 그림이 없어 사용자가 파일을 주어야 함.
2. 내용 정리 카드 ⓓ 헷갈리는 비교를 더 보강할지(현재 일부 카드만 있고 근거 없는 칸은 비워 둠).
3. Notion 정리: 구판 블록과 오래된 복원표 삭제 여부(사용자 승인 필요).
4. 블라인드 짝 찾기 마무리: 압축 파일, '단치 야마', '@야마보관소Global' 미검사.
5. 증거 배지(T6/T2′) 표시.
6. 정답 확정이 필요한 문항 묶음: 29-6(B12/MH4 오기 의심), 정답 상태가 충돌·추론·추정인 문항. 시험 범위 공지 원문도 미확인.
7. 23학번 시험지에는 Ch.30 문항이 없음(원문 Q1~80 확인). 퀴즈에 넣은 Ch.30 17문항은 타 학번 시험에서 온 것이며 모두 '추정' 정답.
