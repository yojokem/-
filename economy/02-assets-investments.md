# 02. 자산/투자 현황 추적

> 소스 연동 전 템플릿. 실제 값은 Notion/Drive 연동 후 채운다.

## 스냅샷 템플릿 (기준일: YYYY-MM-DD)

| 구분 | 항목 | 평가금액 | 비중 | 출처 |
|---|---|---|---|---|
| 현금성 | 예적금/CMA | - | - | - |
| 투자 | 국내주식 | - | - | - |
| 투자 | 해외주식/ETF | - | - | - |
| 투자 | 연금(퇴직/개인) | - | - | - |
| 부동산 | - | - | - | - |
| 부채 | 대출/카드할부 | - | - | - |
| **순자산 (자산 − 부채)** | | **-** | | |

## 추적 규칙

- ◦ 매월 동일 기준일(예: 말일)에 스냅샷을 남겨 시계열 비교가 가능하게 한다.
- ◦ 평가금액이 큰 변동(예: ±10% 이상)이 있으면 원인(시장 변동 vs 입출금)을 비고로 구분한다.
- ◦ 목표 자산배분(예: 현금 20% / 투자 70% / 기타 10%)이 정해지면 이 문서 상단에 별도로 명시한다.

## 향후 확장

- 월별 스냅샷을 누적해 `dashboard.html`의 순자산 추이 차트에 반영
- 목표 대비 진척률(목표 순자산, 은퇴/독립 시점 등)은 사용자와 목표를 합의한 뒤 추가
