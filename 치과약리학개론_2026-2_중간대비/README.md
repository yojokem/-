## 다시 만들기
```
cd build
python3 assemble.py   # data.json 생성 (+ 중복 묶음 dups/rep 계산)
python3 mk.py         # page.html 생성
node t.js; node t2.js; node t3.js; node t4.js   # playwright 점검 (page.html을 file://로 열어 확인)
```
`mkimg.py`는 `sources/`의 PDF에서 그림을 뽑아 `imgs.json`을 만듭니다(경로는 스크립트 안 상수 확인).
