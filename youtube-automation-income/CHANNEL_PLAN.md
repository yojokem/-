# 채널 기획 (미국 시장 타겟)

세부 사항은 진행하면서 확정 (들이닥치면 생각). 이 문서는 지금 시점에 필요한 **니치/콘텐츠 기획**만 확정한다.

> 판단 기준/트리거가 여러 문서에 흩어져 있으면 헷갈리니, 요약 색인은 `CHECKPOINTS.md`에서 확인.

서브니치를 "행동신호 해독"으로 좁히는 안(대형 채널 Psych2Go와의 차별화 목적)을 검토했으나, **현행 4필러 일반 심리학 팩트 구성을 그대로 유지**하기로 했다. 재검토 조건은 아래 "니치/앵글 재검토 트리거" 참고.

## 왜 미국 타겟인가 (전제 확인)

- 유튜브 쇼츠 광고 단가(RPM)가 한국 대비 미국이 대체로 높음
- 얼굴/목소리 비노출 + 영어 TTS(타입캐스트 영어 보이스 지원) 조합이면 언어 장벽 없이 바로 시작 가능
- 미국 대상이면 자막도 영어로만 가면 되고, 스톡 소스 풀이 훨씬 큼(카피라이트 프리 소스 대부분 영어권 중심)

## 니치 후보 비교

| 니치 | 장점 | 단점 | RPM 체감 |
|---|---|---|---|
| **Did You Know / 잡학 사실** | 소재 무한, 스크립트 쓰기 쉬움, TTS와 궁합 좋음 | 경쟁 매우 많음 | 중 |
| **Reddit 스토리 각색** (AITA, relationship, revenge) | 조회수 잘 나옴, 소재는 Reddit에서 각색 | 저작권/각색 범위 주의, 미국 커뮤니티 정서 이해 필요 | 중~상 |
| **Psychology / 자기계발 facts** | RPM 상대적으로 높음(교육/자기계발 카테고리), 재사용성 높음 | 소재 리서치에 시간 필요 | 상 |
| **Scary / Paranormal 단편** | 몰입도 높고 완주율(retention) 좋음 | 유튜브 정책상 과도한 공포 연출 주의, 광고주 친화도 낮을 수 있음 | 중 |
| **Money / Finance tips (짧은 팁)** | RPM 최상위권 | 정확성 요구 높음, 잘못된 정보 리스크, 초보가 다루기엔 진입장벽 | 최상 |

## 추천: **Psychology / Self-Improvement Facts** 니치 (1순위)

이유:
- 광고주 친화적 카테고리라 RPM이 상대적으로 안정적
- "did you know" 포맷과 결합 가능 (예: "심리학이 밝혀낸 사실 5가지")
- 소재가 학술/일반 지식 기반이라 저작권 리스크 낮음
- 미국뿐 아니라 영어권 전체로 확장 가능 (영국/캐나다/호주 트래픽도 흡수)
- TTS 톤(차분하고 신뢰감 있는 보이스)과 잘 맞음

**정체 시 전환 순서**:
1. **먼저: 같은 니치 안에서 포맷 다각화** — 검증된 쇼츠 소재를 롱폼으로 재구성(STRATEGY.md 5절), 또는 서브니치 세컨 채널 분리. 톤/리서치 인프라를 그대로 재사용하는 저위험 옵션이라 우선 시도.
2. **최후수단: Reddit 스토리 각색 채널** — 조회수는 빨리 나올 수 있지만 매번 새 캐릭터/서사가 필요해 "차분하고 권위 있는" 채널 톤과 결이 다르고, 외주화 없이 직접 쓰면 리서치·작문 부담이 큼. 포맷 다각화로도 정체가 안 풀릴 때만 검토.

## 시간 투입 상한선 원칙

다른 계정(채널 8개, 하루 12~17시간, 주7일, 1년 반 운영, 본인 표현 "셀프노동착취")의 그라인드 사례를 확인했다. 이 프로젝트는 하루 2~3시간·단일 채널을 상한선으로 유지한다.

- **하루 2~3시간, 주 5~6일을 넘는 투입이 상시로 필요해지면**, 그건 "더 노력해야 한다"는 신호가 아니라 **이 니치/포맷이 지금 예산 구조에 안 맞는다는 신호**로 본다 → 대본/편집 단순화, 필러 정리, 업로드 빈도 축소를 먼저 검토한다.
- 그라인드 사례처럼 멀티채널·새벽 작업·주7일 무휴로 확장하는 방향은 명시적으로 채택하지 않는다.

## 채널 아이덴티티 초안

- 채널명 후보: `MindByte`, `The Quiet Insight`, `Psych Shorts`, `KnowMind`
- 톤: 차분하고 권위 있는 내레이션, 문장 짧고 단정적
- 업로드 주기: 미국 시간대 기준 저녁~밤(EST 오후 7~10시) 골든타임에 맞춰 예약 업로드 → 한국 기준 오전 8~11시경

### 제목/훅/썸네일 패턴

**제목 패턴**
- 번호+단정형: `5 Signs You're a [특성]`, `3 Psychology Tricks That [결과]`
- 질문형: `Why Do We [행동]?`
- 반전/재정의형: `It's Not [통념], It's [진짜 이유]`
- "cure/diagnose/treatment" 같은 의료 단정 표현은 피하고 "study suggests/psychology explains" 톤 유지 (광고주 친화도·정책 리스크)
- 30~40자 내외, 첫 3~4단어에 후킹 단어(Why/Secret/Sign/Trick) 배치

**훅(오프닝 3초 대사) 패턴**
- 직접 지목형: "You do this every single day and don't even notice."
- 역설 제시형: "The smarter you are, the more likely you are to fall for this."
- 카운트다운 예고형: "Here are 3 signs your brain is lying to you."
- 첫 문장에 배경 설명("Today we'll talk about...")을 넣지 않는다 — 첫 단어부터 훅

**썸네일(첫 프레임 텍스트 오버레이) 패턴**
- Shorts는 정지 썸네일보다 첫 프레임 텍스트 오버레이가 실질적 썸네일 — 핵심 문구 3~5단어를 화면 상단/중앙에 큰 볼드체로
- 색상: 신뢰감(네이비/딥블루) + 주의환기 강조색(옐로/레드) 대비
- 얼굴이 없으므로 뇌 일러스트/실루엣/추상 아이콘 같은 저작권 프리 비주얼 모티프를 채널 고유 스타일로 고정 (반복 노출 자체가 브랜드가 됨)

### 니치/앵글 재검토 트리거

**누적 20편 업로드 시점**에 아래를 확인:
- 평균 시청 지속률이 50% 미만인 영상이 과반이면 → 서브니치 좁히기(행동신호 해독 등, 이전 감사 결과 참고)를 재검토
- 필러별 성과 편차가 크면(특정 필러가 확실히 하위권) → 그 필러 비중 축소, 상위 필러로 재배치
- 이 기준에 도달하기 전에는 4필러 구성을 바꾸지 않는다 (표본 부족 상태에서 포맷 흔들지 않기)

## Day 0 착수 체크리스트

기획은 이미 실행 가능한 수준이라는 판단 — 남은 건 손으로 해봐야 아는 것들뿐이라 계정가입/제작 등 실무는 아래 순서로 착수한다. 결제가 필요한 항목(TTS 초과분 등)만 사용자 승인 후 진행, 나머지 무료 항목은 바로 진행 가능.

1. 채널명 최종 1개 확정(후보: `MindByte`, `The Quiet Insight`, `Psych Shorts`, `KnowMind` — 핸들 중복만 빠르게 확인) + 유튜브 채널 개설, 프로필/설명 세팅 (~30분)
2. 캡컷 가입 + 인터페이스 훑어보기(자막 자동생성/템플릿 저장 기능 위치 확인) (~20분)
3. 무료 스톡 소스 1~2곳 계정 생성 (Pexels/Pixabay 등, 결제 없는 곳부터) (~10분)
4. 타입캐스트 API 키 발급(무료 티어) + 영어 보이스 후보 청취 후 1개 선정, Google Cloud TTS도 백업용으로 계정만 만들어둠 (~20분)
5. ep01 대본 작성 (`templates/shorts_script_template.md`, negativity bias 리서치는 이미 A급 완료 — `research/sources_log.csv` 참고) (~30분)
6. TTS 생성 → 스톡 소스 확보 → 캡컷 편집 → 업로드 메타데이터/예약 (~2시간, 첫 편이라 캡컷 편집은 문서 추정보다 길게 잡을 것)
7. 유튜브 업로드와 동시에 TikTok/Instagram Reels에도 같은 영상 업로드 (재편집 없이, STRATEGY.md §1 배포 다각화 원칙)

**Day 0 총합은 3.5~4.5시간으로 하루 2~3시간 상한선을 넘긴다 — 이건 원칙 위반이 아니라 "1회성 셋업 비용"으로 명시적 예외 처리한다.** ep02부터 실제로 2~3시간 안에 들어오는지가 진짜 검증 포인트.

**착수 후 1주일 내 반드시 확인**: (1) 캡컷 편집 실측 시간이 예상(40~60분)과 맞는지 — 90분+로 나오면 "매일 1편" 페이스 자체를 STRATEGY.md §4에서 즉시 재조정해야 함. (2) 필러3(생산성/습관) 리서치가 다른 필러보다 실제로 얼마나 더 걸리는지.

**여전히 진행하며 결정할 것**: 썸네일 텍스트 오버레이 구체 폰트/컬러(가이드라인은 위 "제목/훅/썸네일 패턴" 참고), 정확한 업로드 요일 패턴.
