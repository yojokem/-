# 유튜브 쇼츠 자동화 수익화 프로젝트

얼굴 비노출(목소리는 본인 육성), 미국(영어권) 타겟의 유튜브 쇼츠 채널. 니치는 심리학/자기계발 팩트와 글로벌 법/제도 트렌드를 파일럿으로 비교 중이며 아직 확정 전이다(`CHANNEL_PLAN.md` 파일럿 게이트 참고). 하루 2~3시간·단일 채널을 상한선으로 잡고 반자동 파이프라인으로 운영한다. 수익 숫자(월 650만원 등)는 목표가 아니라 검증 안 된 참고 사례로만 취급한다.

## 읽는 순서

1. **`STRATEGY.md`** — 왜/무엇을: 핵심 전제, 제작 파이프라인, 성장 단계, 리스크, **역할 분담(§7 — 저작권 등 법적 판단은 에이전트가 아니라 사람이 최종 확인)**
2. **`CHANNEL_PLAN.md`** — 니치·채널 아이덴티티 확정, 제목/훅/썸네일 패턴, 초기 20편 소재 리스트, **Day 0 착수 체크리스트**(실제 시작은 여기부터)
3. **`research/RESEARCH_WORKFLOW.md`** — 제작 전 사실검증 절차, 주간 배치 루틴
4. 이후 상시 참조: **`CHECKPOINTS.md`** (판단 기준/트리거 색인 — 언제 조정하고 언제 접을지)
5. 영상 편집이 처음이라면: **`PRODUCTION_GUIDE_FOR_BEGINNERS.md`** (대본 완성 후 업로드까지, 버튼 단위로 쪼갠 설명)

파일럿 트랙(심리학 vs 글로벌 법/제도 트렌드 비교 중)의 소재 기준은 `research/TRENDS_TOPIC_CRITERIA.md` 참고 — 니치 확정 전까지는 실험용.

## 폴더 구조

- `research/` — 사실검증 절차(`RESEARCH_WORKFLOW.md`), 필러별 출처 등급표(`SOURCE_DIRECTORY.md`), 에피소드별 검증 기록(`sources_log.csv`), 소재 중복 방지 로그(`concept_log.csv`)
- `templates/` — 대본 템플릿, 훅/CTA 문장 라이브러리(`hook_library.md`), 콘텐츠 캘린더, 자산 라이선스 로그, 성과 기록(`performance_log.csv`, ep01 업로드부터 채움)
- `automation/` — 업로드 메타데이터 생성 보조 스크립트, TTS는 백업 옵션용 보조 스크립트 (캡컷 편집·실제 업로드·기본 녹음은 자동화 대상 아님)
- `episodes/` — 에피소드별 실제 산출물(대본/음성/소스 기록). 미디어 파일은 `.gitignore` 처리
