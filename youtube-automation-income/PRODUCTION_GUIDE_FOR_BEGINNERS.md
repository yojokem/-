# 영상 제작 과정 (완전 처음 보는 사람 기준)

"편집"이라는 말이 막연하게 느껴질 수 있는데, 실제로는 정해진 순서대로 파일 몇 개를 조립하는 작업이다. 아래는 대본이 완성된 다음부터 업로드까지, 실제로 뭘 누르고 뭘 만드는지 순서대로 푼 것.

## 큰 그림: 재료 3개를 합치는 작업

영상 하나는 결국 **① 목소리(오디오) + ② 화면에 나오는 영상/이미지 + ③ 자막**, 이 세 가지를 시간축에 맞춰 겹쳐놓은 것뿐이다. 순서대로 하나씩 준비해서 CapCut(영상 편집 앱)에 쌓아 올리면 끝난다.

## 1단계: 목소리 만들기 (본인 육성 녹음)

- 대본을 직접 읽어서 녹음한다 — 스마트폰 녹음 앱으로도 충분하다 (조용한 방에서, 마이크와 입 거리 15~20cm 정도)
- 완벽하게 안 읽어도 된다 — 말 씹히거나 버벅이는 부분은 편집 단계에서 그 구간만 다시 녹음해서 이어붙이면 됨
- 이게 영상의 "뼈대"다 — 이 음성 파일의 길이가 결국 영상 전체 길이를 정한다 (30~59초)
- 녹음 파일을 `episodes/ep01-B.mp3` 같은 이름으로 저장해둔다
- (백업) 목소리 컨디션이 안 좋은 날이나 급할 때는 타입캐스트/Google TTS로 대체 가능 — `automation/README.md` 참고, 다만 기본은 육성
- 대본은 폰으로 녹음하면서 다른 화면(PC/태블릿) 또는 출력물로 보면서 읽는다 — 녹음 중인 폰 화면에 대본을 띄우기는 어려우니 미리 정해둘 것

## 2단계: 화면에 나올 영상/이미지 모으기

- 대본을 문장 단위로 나눠보면(`shorts_script_template.md`의 "컷 타이밍" 항목) 각 문장마다 화면에 뭐가 보여야 할지 대충 감이 온다
  - 예: "California banned plastic bags in 2014" → 마트에서 비닐봉투 쓰는 장면
  - "Then bag waste went up 47%" → 쓰레기 더미, 통계 그래프 느낌의 영상
- Pexels/Pixabay 같은 무료 영상 사이트에서 각 문장에 맞는 클립을 검색해서 다운로드 (문장당 클립 1개, 총 4~6개 정도면 충분)
- 클립 길이는 신경 안 써도 된다 — 편집 단계에서 어차피 잘라서 쓴다

## 3단계: CapCut에서 조립하기 (실제 "편집")

여기가 제일 생소하게 느껴질 부분이라 순서를 아주 잘게 쪼갰다:

1. **새 프로젝트 열기** (미리 만들어둔 "템플릿 프로젝트" 복제해서 시작하면 자막 스타일/배경음악 트랙이 이미 세팅돼 있음)
2. **오디오 트랙에 mp3(1단계 결과물) 넣기** — 이게 타임라인의 기준이 됨
3. **영상 트랙에 2단계에서 모은 클립들을 순서대로 배치** — 각 클립을 오디오의 해당 문장 구간 길이에 맞춰 드래그해서 자르기 (클립이 문장보다 길면 뒷부분 잘라내면 됨, 어려운 기술 아니고 그냥 드래그)
4. **자막 자동 생성 버튼 누르기** — CapCut이 mp3 음성을 인식해서 자막을 자동으로 만들어줌 (사람이 타이핑 안 해도 됨). **주의(2026-08-25 확인)**: 2025년 가격 개편 이후 자동자막이 완전 무료는 아니고 무료 플랜은 월 몇 회로 쿼터 제한이 있다 — 파일럿 1~2편은 무료 쿼터 안에 들어가지만, 나중에 매일 업로드 페이스가 되면 쿼터 소진 여부를 확인할 것. 쿼터 소진 시 백업은 자막 수동 타이핑
5. **자막 스타일 한 번에 적용** — "Apply to all captions" 버튼으로 미리 만들어둔 스타일(폰트/색)을 자동 생성된 자막 전체에 한 번에 입힘
6. **배경음악 트랙 추가** (캡컷 내장 음악 말고 YouTube Audio Library 등에서 받은 로열티프리 음원 — `STRATEGY.md` §2 참고)
7. **미리보기로 한 번 재생해서 오디오-영상-자막이 다 맞는지 확인**
8. **내보내기(Export)** — mp4 파일로 저장됨

이게 전부다. "편집"이라고 하면 거창하게 느껴지지만 실제로는 **"음성 파일 위에 어울리는 영상 조각을 순서대로 붙이고, 자동 자막 버튼 누르고, 음악 깔고 내보내기"**가 전부라서, 한 번 해보면 두 번째부터는 훨씬 빨라진다.

## 4단계: 업로드

- 유튜브 스튜디오에 mp4 업로드 → 제목/설명/태그 입력(`prep_upload_metadata.py`로 초안 뽑아도 됨) → 예약 업로드 또는 바로 게시
- 파일럿 단계에서는 **Unlisted(비공개 링크)**로만 올리기 — `CHANNEL_PLAN.md` 파일럿 게이트 참고
- 채널을 따로 안 만들어도 된다 — Google 계정으로 유튜브에 로그인하면 기본 채널이 자동으로 존재해서 그걸로 바로 업로드 가능. 채널명/아이콘 같은 브랜딩은 니치가 확정된 뒤에 정해도 됨
- 배경음악은 YouTube Studio의 Audio Library에서 받는다(로그인만 하면 접근 가능)
- 스톡 클립을 받을 때마다 `templates/asset_license_log.csv`에 출처/라이선스를 바로바로 기록해둘 것 — 나중에 몰아서 하면 누락되기 쉽다

## 처음 할 때 예상되는 것

- 첫 편은 각 단계에서 버튼 위치를 찾느라 예상보다 오래 걸릴 수 있다 (`CHANNEL_PLAN.md` Day 0 체크리스트도 캡컷 편집을 40~60분이 아니라 더 길게 잡아뒀다) — 정상이다
- 두세 번째부터는 템플릿 프로젝트를 복제해서 시작하기 때문에 반복 작업(자막 스타일 설정 등)이 사라져서 확 빨라진다
- 막히는 지점이 생기면 그 부분만 캡처해서 물어보면 됨 — 전체를 다 알아야 시작할 수 있는 게 아니라, 막힐 때마다 그 한 단계만 풀면 됨
