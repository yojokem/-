# 유튜브 쇼츠 자동화 수익화 전략

원본 참고: Threads @short_tuber 게시물 요약 — "캡컷 + 타입캐스트 6만원이면 얼굴/목소리 노출 없이 월 최대 650만원까지 찍었다, 하루 2~3시간이면 된다."

이 문서는 그 주장을 실행 가능한 파이프라인으로 정리한 것이다. **숫자(월 650만원)는 검증되지 않은 개인 주장**이므로 목표가 아니라 "상한선 사례"로만 취급한다.

> **2026-08-25 재검 결과 (감사관 반영)**: 채널 8개를 하루 12~17시간·주7일·1년 반 운영한 다른 계정의 실사례를 확인했다. "월 650만원" 같은 상한선 주장은 하루 2~3시간 단일 채널이 아니라 **이런 자릿수가 다른 시간 투입에서 나왔을 가능성이 높다** — 이 숫자는 참고 관계가 아니라 "다른 리그의 사례"로 재분류하고, 목표 설정 시 더 이상 인용하지 않는다.

> **타겟 확정: 미국(영어권) 시장.** 대본/자막/업로드 메타데이터는 모두 영어로 제작한다. 구체적 니치/소재 기획은 `CHANNEL_PLAN.md`, 소재 사실검증 절차는 `research/RESEARCH_WORKFLOW.md` 참고.

## 1. 핵심 전제

- **얼굴/목소리 비노출**: TTS(타입캐스트) + 스톡/생성 영상·이미지로 편집
- **저비용 툴체인**: 캡컷(무료~유료 저가) + 타입캐스트(TTS, 유료 저가)
- **시간 투입**: 하루 2~3시간, 즉 완전 자동화가 아니라 "반자동 + 대량 생산" 구조
- **실패 요인**: 대부분 "나중에" 하다가 안 함 → 실행 마찰을 줄이는 게 핵심

## 2. 채널 설계 체크리스트

1. **니치 선정**: 정보/썰/퀴즈/자기계발/동물/스토리 중 경쟁도 낮고 소재 고갈이 없는 카테고리
2. **포맷 고정**: 도입 후킹 3초 → 본론 → 마지막 반전/CTA. 매 영상 동일 템플릿 사용
3. **채널 아이덴티티**: 제목/썸네일/톤 통일 (얼굴 없이도 브랜드가 되도록)
4. **저작권 리스크 점검**: 스톡 소스, TTS 목소리 라이선스, 배경음악 라이선스 반드시 확인

## 3. 제작 파이프라인 (하루 2~3시간 기준)

```
[0] 소재 사실검증 (10~15분)
    └ research/RESEARCH_WORKFLOW.md 절차대로 WebSearch로 교차검증 → research/sources_log.csv 기록
[1] 소재/대본 (30분)
    └ 대본 템플릿(templates/shorts_script_template.md) 채우기
[2] TTS 음성 생성 (10분)
    └ 타입캐스트로 대본 → 음성 파일(mp3/wav)
[3] 영상 소스 수집/생성 (30~40분)
    └ 스톡 영상/이미지 또는 AI 생성 영상 클립 확보
[4] 캡컷 편집 (40~60분)
    └ 자막 자동 생성, 컷 편집, 배경음악, 템플릿 적용
[5] 업로드 & 메타데이터 (10분)
    └ 제목/설명/태그/썸네일, 예약 업로드
```

캡컷은 공개 자동화 API가 없으므로 4번 편집 단계는 **수작업 유지**가 현실적이다. 1~2번(대본, TTS)과 5번(업로드 메타데이터 작성)은 스크립트로 보조 자동화가 가능하다 → `automation/` 참고.

## 4. 수익화 단계

| 단계 | 조건 | 액션 |
|---|---|---|
| 초기 (0~2개월) | 구독자 0 | 매일 1편 업로드(주 5~6일), 포맷 고정, 데이터 쌓기 |
| 검증 (2~6개월) | 조회수 편차 확인 | 잘 되는 포맷 3개로 압축, 나머지 중단 |
| 수익화 (6개월~) | 유튜브 파트너 프로그램 조건 충족 | 광고 수익 + 롱폼 병행으로 안정화 |
| 확장 | 채널 안정화 | 세컨 채널 or 롱폼 요약본으로 영역 확장 |

> 2026-08-25 수정: "매일 1~2편"은 섹션 3 파이프라인의 하루 2~3시간 예산과 충돌해서 "매일 1편(주 5~6일)"로 낮췄다. 각 단계 기간도 그라인드 사례(하루 12시간+) 대비 시간당 투입이 훨씬 적다는 점을 반영해 늘려 잡았다.

## 5. 가끔 롱폼 병행 전략

- 쇼츠에서 반응 좋았던 소재 3~5개를 묶어 8~15분 롱폼으로 재구성
- 롱폼은 쇼츠 대비 광고 단가가 높고 알고리즘 노출 채널이 다름 → 채널 안정화 이후 월 1~4편 정도로 병행
- 롱폼 스크립트는 쇼츠 대본을 확장하는 방식으로 제작 (완전히 새로 안 씀)

## 6. 리스크와 현실 점검

- 캡컷+타입캐스트 비용은 시작 비용이지, 성공 보장이 아님 — 대부분의 채널은 초반 몇 달간 수익이 거의 없음
- "6,500,000원"은 최대치 사례이며 재현 가능성 낮음. 현실적 목표는 6~12개월 내 손익분기(툴 비용+시간 회수) 정도로 잡는 것을 권장 (2026-08-25 수정: 기존 3~6개월은 하루 2~3시간 전제 대비 낙관적이라 늘려 잡음)
- 플랫폼 정책 변화(쇼츠 수익 배분율, AI 생성 콘텐츠 라벨링 의무화 등) 리스크 상시 확인 필요
- 반면교사(타 계정 사례): 소재 수집 후 대본·편집을 통째로 외주화했더니 톤/품질이 무너져 조회율이 급락한 사례가 있음 → 사실검증·톤 관리는 계속 직접(에이전트) 담당하고, 아직 과금 여력이 크지 않으니 유료 트렌드분석 툴(ViewMine 등) 같은 외부 결제 도구도 당장은 도입하지 않는다
- 번아웃/그라인드 압박: 다른 계정(채널 8개, 하루 12~17시간, 주7일, 1년 반, 본인 표현으로 "셀프노동착취")이 실제로 존재함 — 이건 벤치마킹 대상이 아니라 반례. 이 프로젝트는 하루 2~3시간·단일 채널 상한선을 넘기지 않는 게 원칙이며, 그 상한선을 넘겨야만 결과가 나올 것 같은 압박이 느껴지면 그건 "포맷 조정" 신호이지 "시간을 늘릴" 신호가 아니다
