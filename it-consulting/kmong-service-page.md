# 크몽 서비스 페이지 문구 — "IT 시스템 자문/진단"

카테고리: IT·프로그래밍 > 컨설팅 (IT 컨설팅/시스템 자문)

---

## 서비스명 (제목, 40자 내외)

1인 개발자·초기 스타트업을 위한 시스템 진단 + 개선 로드맵 컨설팅

*(대체안)*
- 코드 대신 방향을 드립니다 — DB·API·배포·보안 구조 진단
- 우리 서비스 구조, 지금 이대로 괜찮을까요? IT 시스템 자문

---

## 한 줄 요약

"코드를 대신 짜드리지 않습니다. 지금 구조의 리스크를 짚고, 무엇을 먼저 손봐야 하는지 리포트와 로드맵으로 정리해 드립니다."

---

## 이런 분께 추천합니다

- MVP는 돌아가지만 "이대로 확장해도 되는지" 불안한 1인 개발자
- 개발자를 새로 뽑기 전에 지금 구조를 외부 시선으로 점검받고 싶은 초기 스타트업
- DB 설계, API 구조, 배포 파이프라인, 보안 기초 중 어디부터 손대야 할지 우선순위가 필요한 팀
- "일단 다 고쳐주세요"가 아니라 "무엇을, 왜, 어떤 순서로"가 필요한 분

## 이런 분께는 맞지 않습니다

- 코드를 직접 작성/구현해 줄 개발자가 필요한 경우 (본 서비스는 진단·자문형이며, 실행은 의뢰인 몫입니다)
- 대규모 조직의 아키텍처 리뷰나 장기 상주 컨설팅

---

## 제공 내용

1. **사전 인터뷰 (비동기 또는 짧은 통화)**: 서비스 목적, 현재 스택, 트래픽/데이터 규모, 가장 불안한 지점 파악
2. **구조 점검**: DB 설계, API 구조, 배포 환경, 보안 기초 항목을 코드/설정 기준으로 확인
3. **진단 리포트 전달**: 구조적 리스크 우선순위 3가지 + 근거 + 방치 시 예상되는 문제
4. **개선 로드맵**: 단기(즉시 조치)/중기(1~2개월)/장기(구조 개선) 순서로 실행 가능한 액션 아이템
5. **후속 Q&A**: 리포트 전달 후 1회 정리 답변 (범위 내)

## 제공하지 않는 것

- 코드 구현, 배포 대행, 서버 운영 대행
- 리포트 이후의 실행/개발 작업 (별도 협의 시 진행 가능)

---

## 왜 저에게 맡겨야 할까요

- 학생부 컨설팅으로 다져진 **"복잡한 현황을 진단하고 구조화된 리포트로 전달하는" 역량**을 IT 시스템에 적용합니다.
- 개발 실력은 화려한 신기술 스택보다 **"뭐가 문제인지 명확하게 짚어내는 것"**에 강점이 있습니다.
- 문의부터 리포트 전달까지 **빠른 응답 속도**로 진행합니다.

---

## 진행 절차 (예시)

1. 요청서 작성 (서비스 개요, 스택, 걱정되는 부분)
2. 사전 확인 및 범위 조율
3. 진단 진행 (영업일 기준 N일)
4. 리포트 + 로드맵 전달
5. 후속 Q&A

## 패키지 구성 (예시, 가격은 별도 확정 필요)

- **베이직**: 리포트 (리스크 3가지 + 우선순위) — 소규모 서비스, 단일 영역(DB 또는 API) 집중 점검
- **스탠다드**: 리포트 + 개선 로드맵 (DB/API/배포/보안 전체 스캔)
- **프리미엄**: 스탠다드 + 후속 화상 미팅 1회 (로드맵 설명 및 질의응답)
