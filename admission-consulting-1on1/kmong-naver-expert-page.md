# 입시 상담 단발 소액 상품 — 크몽 / 네이버 지식iN 엑스퍼트용

기존 학생부 컨설팅(장기·풀케어)과는 분리된 상품. 부담 적은 "시간 단위 상담"으로 쪼개서 진입장벽 낮추기.

---

## 서비스명

1회 30분, 학생부/입시 전략 1:1 상담 (경력 O년, 실전 진단)

*(대체안)*
- 학생부 어디부터 손봐야 할지 모르겠다면 — 30분 진단 상담
- 입시 전략, 긴 컨설팅 계약 없이 딱 필요한 만큼만

## 한 줄 요약

"풀 컨설팅 계약 없이, 지금 가장 궁금한 것 하나만 30분 안에 명확하게 짚어드립니다."

---

## 이런 분께 추천합니다

- 학생부/생기부를 어떻게 채워야 할지 방향만 빨리 잡고 싶은 학부모·학생
- 이미 다른 곳에서 컨설팅 받고 있지만 세컨 오피니언(제3자 의견)이 필요한 경우
- 장기 계약은 부담스럽고, "이번 한 번"만 물어보고 싶은 경우

## 제공 내용

- 상담 전 간단한 정보 요청 (현재 학년, 목표 계열/학교, 현재 학생부 상황 등)
- 30분 1:1 상담 (화상 또는 음성, 네이버 지식iN 엑스퍼트는 텍스트/음성 선택 가능)
- 상담 중 나온 핵심 포인트 요약 1~2줄로 정리해 전달 (다시 찾아볼 수 있게)

## 제공하지 않는 것

- 학생부 항목 직접 작성/첨삭 (이건 별도 풀 컨설팅 영역 — 필요시 안내만)
- 장기 진행 관리, 정기 미팅

---

## 가격 (예시, 확정 필요)

- **30분 단발 상담**: 3~5만원대 (지식iN 엑스퍼트 기본 상담권 시세 참고해서 조정)
- **60분 상담**: 30분의 1.5~1.8배 수준

## 배포처별 차이

| | 크몽 | 네이버 지식iN 엑스퍼트 |
|---|---|---|
| 형태 | 서비스 페이지 등록, 채팅 문의 → 예약 | 프로필 등록 후 질문자가 바로 예약/질문 |
| 강점 | 이미 IT 컨설팅으로 계정 있으면 카테고리만 추가하면 됨 | 네이버 검색 유입 자체가 광고 없이 큼, 입시 카테고리 수요 꾸준 |
| 등록 난이도 | 무료, 바로 가능 | 전문가 인증 절차 필요할 수 있음 (경력 증빙 등) — 확인 필요 |

**추천 순서**: 크몽에 먼저 등록(빠름) → 지식iN 엑스퍼트는 인증 절차 확인 후 병행.

## 등록 전 체크리스트

- [ ] 기존 학생부 컨설팅 계약상 사업자 등록 제약이 "단발 개인 프리랜서 상담"에도 적용되는지 재확인 (풀 컨설팅과 다른 형태이므로 괜찮을 가능성 높으나 확인 필요)
- [ ] 경력/실적 소개 문구 (구체적 숫자·사례 있으면 신뢰도 상승)
- [ ] 가격 확정
- [ ] 크몽 계정에 카테고리 추가 or 신규 등록
- [ ] 네이버 지식iN 엑스퍼트 가입 절차 확인
