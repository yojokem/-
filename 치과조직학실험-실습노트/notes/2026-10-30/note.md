# PART 1. 이론 — 호흡기계통 (교안 순서대로)

## 0. 호흡기계통 개요 — 분지와 구성
이미지(교안): `../../images/교안/resp_theory_p01_overview.jpg`, `../../images/교안/resp_theory_p02_conducting-respiratory.jpg`

- **상기도 / 하기도** : Upper respiratory tract = 비강·인두 / Lower respiratory tract = 후두·기관·기관지·폐(세기관지·호흡세기관지·폐포관·폐포) + 흉막·가로막(diaphragm).
- **분지(branching)** 가 진행될수록 → **단면 직경의 합계(total cross-sectional diameter)가 증가** → **공기 속도(velocity of air flow)는 감소**.

| 구분 | 구성 | 기능 |
|---|---|---|
| **Conducting portion(통로부분)** | Nasal cavity · Nasopharynx · Larynx · Trachea · Bronchus(-i) · Bronchioles(Terminal bronchiole 포함) | 공기 **수송**, 공기를 **거르고(filter) 축축하게(moisten) 데움(warm)** / 구조 유지 + **유연성·신장성** |
| **Respiratory portion(호흡부분)** | Respiratory bronchiole · Alveolar duct · Alveolar sac(Atrium) · Alveolus(-i) | **가스교환** |

- 계통 흐름(암기) : **Nasal cavity → Nasopharynx → Larynx → Trachea → Bronchus → Bronchiole → Terminal bronchiole │ → Respiratory bronchiole → Alveolar duct → Atrium → Alveolar sac(saccule) → Alveolus**.

## 1. 호흡상피(Respiratory epithelium)
이미지(교안): `../../images/교안/resp_theory_p05_respiratory-epithelium.jpg`, `../../images/교안/resp_theory_p06_ciliated-cell-EM.jpg`

- **통로부분의 상피** = **거짓중층섬모원주상피(PCCE, Pseudostratified ciliated columnar epithelium)**.
- **전자현미경에서 구분되는 5종 세포**

| 세포 | 특징 |
|---|---|
| **1. Ciliated columnar cell(섬모원주세포)** | **가장 많다.** 자유표면에 **섬모 약 300개**, 섬모 아래 **기저소체(basal body)**, 섬모운동 → **미토콘드리아(ATP 공급) 많다** |
| **2. Mucous goblet cell(점액술잔세포, G)** | **점액방울(mucous droplet)**(당단백질)을 **자유표면 쪽 세포질**에 함유 |
| **3. Brush cell(솔모양세포)** | 원주세포의 일종, 자유표면에 **미세융모(microvilli)** 많음, **감각수용기**로 생각됨 |
| **4. Basal cell / Short cell(기저세포, 짧은세포)** | **발생세포(generative cell)** 로 추측 |
| **5. Small granule cell(소과립세포)** | 중심부 **전자밀도 높은 과립** 다수, **산재성내분비계통(DNES, diffuse neuroendocrine system)** |

- 한눈에 : **섬모세포(가장 많음, 섬모) / 술잔세포(점액) / 솔모양세포(감각) / 기저세포(재생) / 소과립세포(내분비)**.

## 2. 비강(Nasal cavity) — A
이미지(교안): `../../images/교안/resp_theory_p09_nasalcavity.jpg`

- **비강 = Vestibule(코전정) + Nasal fossae(코오목)**.

| 구분 | 특징 |
|---|---|
| **Vestibule(코전정)** | 콧구멍(nares, nostrils) 안쪽 · **기름샘(sebaceous)·땀샘(sweat)·코털(vibrissae)** · 안쪽으로 가면서 **각질층 소실** · 코오목으로 들어가기 전 **호흡상피로 전환** |
| **Nasal fossae(코오목)** | **코중격 뼈부분(osseous nasal septum)** 이 두 공간으로 분리 · **3개의 코선반(conchae)** = 위(superior)·중간(middle)·아래(inferior) · **위코선반 = 후각상피(olfactory epithelium)** · 나머지 = **호흡상피** |

### 후각상피(Olfactory epithelium)
이미지(교안): `../../images/교안/resp_theory_p10_olfactory-epithelium.jpg`, `../../images/교안/resp_theory_p13_olfactory-cell-diagram.jpg`

- **위코선반**, **PCCE**, **3종 세포** : ① 지지세포 ② 기저세포 ③ 후각세포. + **Bowman's gland(보우만샘)** 존재.

| 세포 | 특징 |
|---|---|
| **지지세포(Supporting cell)** | 기저부 좁고 윗부분 넓은 원통형 · 자유표면에 미세융모 + 그 위 액체층 · **핵이 자유표면 가까이** · 밝은 **노란 색소** |
| **기저세포(Basal cell)** | 작고 둥글거나 **원추형(pyramidal)** · 상피 기저부에 **한 층** · **Regenerative : 3가지 후각상피세포로 분화 가능** |
| **후각세포(Olfactory cell)** | **양극세포(bipolar nerve cell)** · **핵 위치 특이** · **Olfactory vesicle(가지돌기 팽대)** 이 자유표면 쪽으로 돌출 · **후각섬모(olfactory cilia) 6~8개**(긴 부동모) · 후각물질에 반응 → **수용기전압(receptor potential)** |
| **Bowman's gland** | **고유판(lamina propria)** 에 위치 · 분비물 = **후각물질의 용매**, 섬모를 씻어 새 후각물질에 반응할 수 있게 함 |

### 공기 상태의 조절(Conditioning of air) — "깨끗하게 / 따뜻하게 / 축축하게"
| 목적 | 기전 |
|---|---|
| **깨끗하게** | **코털(vibrissae)**, **점액층(layer of mucus)** |
| **따뜻하게** | 표층의 **풍부한 혈관그물(superficial vascular network)** · **역류계통(countercurrent system)** — 혈액과 공기의 흐름이 반대 |
| **축축하게** | ① 점액층·장액성 분비물(muco-serous) ② **팽창체(swell bodies)** = 코선반 점막고유판의 **정맥얼기** — 충혈(20~30분 간격) → 점막 팽창 → 공기 흐름 느려짐 → 습도 유지 |
| **따뜻하게 + 축축하게** | 코선반이 만드는 **좁고 리본모양의 통로** → 표면적↑, 공기 흐름 교란 |

## 4. 후두(Larynx) — C
이미지(교안): `../../images/교안/resp_theory_p18_larynx-cartilages.jpg`

- **인두(pharynx)와 기관(trachea)을 연결**, 불규칙한 모양의 **복잡한 연골 구조**.
- **기능 3가지** : ① **지지**(공기 통로를 열어 둠) ② **판막(valve)** — 음식물·액체가 기관으로 들어가지 않도록 차단 ③ **발성(phonation)** — 성대.
- **연골 분류(암기)**

| 연골 종류 | 해당 연골 |
|---|---|
| **유리연골(Hyaline)** — 큰 연골 | **방패연골(thyroid), 반지연골(cricoid), 모뿔연골(arytenoid) 아래쪽** |
| **탄력연골(Elastic)** — 작은 연골 | **후두덮개(epiglottis), 쐐기연골(cuneiform), 잔뿔연골(corniculate)** |

## 5. 기관(Trachea) — D
이미지(교안): `../../images/교안/resp_theory_p19_trachea-diagram.jpg`, `../../images/교안/resp_theory_p20_trachea-histology.jpg`, `../../images/교안/resp_theory_p22_trachea-epithelium-EM.jpg`

- **후두와 기관지(bronchus)를 연결**. **유리연골고리(C-ring) 16~20개**.
- **섬유탄력인대(fibroelastic ligament)** : **내강의 과도한 팽창에 저항**.
- **기관근육(trachealis muscle)** : **평활근 다발**, **내강 크기 조절** → **기침반사(cough reflex)** : 내강을 좁혀 **공기 속도를 높임**.
- **층 구조(암기)**

| 층 | 구성 |
|---|---|
| **1. Mucosa(점막)** | **Respiratory epithelium**(a. Ciliated columnar cells · b. (Mucous) goblet cells · c. Small granule cells) + 고유판(lamina propria, loose CT) |
| **2. Submucosa(점막밑층)** | **Serous(seromucous) glands** — **술잔세포 + 점액샘 → 점액층 형성** |
| 3. Cartilage layer(Tunica fibromusculocartilaginea) | C-ring 유리연골 + 뒤쪽 trachealis muscle·fibroelastic ligament |
| 4. Adventitia | 결합조직(주변 조직과 경계 없이 이어짐) |

- **이물질 배출 경로** : 술잔세포 + 점액샘 → **점액층** → 이물질이 점액층에 붙음 → **섬모운동으로 밖으로 배출**.
- **Basement membrane(기관의 기저막)** : **25~40 μm로 두껍다** · 상피 기저판 바로 아래 **조밀한 collagen fiber**(고유판의 일부) · **흡연자, 특히 만성 기침 환자에서 더 두꺼움**.

## 6. 기관지나무(Bronchial tree) — E
이미지(교안): `../../images/교안/resp_theory_p23_bronchial-tree.jpg`

- **일차기관지(primary bronchi)** : 기관 → 처음 2개로 분지, **폐문(hilum)** 으로 폐에 들어가 **폐뿌리(pulmonary root = 일차기관지 + A·V·LV·dense CT)** 형성.
- **엽기관지(lobar bronchi)** : 각 폐엽(**우 3 · 좌 2**)으로 → 계속 분지.
- **세기관지(bronchiole)** : 각 **폐소엽**으로 들어감 → 이후 **5~7개의 종말세기관지(terminal bronchiole)** 로 분지.

### 6-1. 기관지(Bronchi)
이미지(교안): `../../images/교안/resp_theory_p24_bronchi-histology.jpg`, `../../images/교안/resp_theory_p25_trachea-vs-bronchi.jpg`, `../../images/교안/resp_theory_p26_bronchi-BALT.jpg`

- **기관 점막과 구조적으로 동일(호흡상피)**. **기관과의 차이**
  1. **점막고유판** : **연골이 불규칙(irregular)** — 완전한 고리 → **연골판(cartilage plate) / 연골섬(cartilage island)** · **풍부한 탄력섬유** · 점액샘·장액샘 · **림프구·림프소절(MALT / BALT)**.
  2. **점막고유판의 평활근층** : **Spiraling smooth muscle 뚜렷해짐(↑)** — **나선형**으로 **십(+)자 모양**으로 엇갈림.

| 구분 | 기관(Trachea) | 기관지(Bronchi) |
|---|---|---|
| 연골 | **C자 고리** 유리연골 | **불규칙한 연골판·연골섬** |
| 평활근 | trachealis(뒤쪽 한 다발) | **나선형 평활근층 뚜렷** |
| 림프조직 | 소수 | **MALT/BALT 림프소절** 발달 |
| 탄력섬유 | 섬유탄력인대 | 풍부 |

### 6-2. 세기관지(Bronchiole)
이미지(교안): `../../images/교안/resp_theory_p27_clara-cell.jpg`, `../../images/교안/resp_theory_p28_bronchiole-histology.jpg`

- **정의** : **직경 1 mm 이하**, **소엽내 기도(intralobular airway)**.
  1. 점막에 **연골이나 샘이 없다**.
  2. **술잔세포(goblet cell)** : 세기관지 **시작 부위에 산재**, **직경이 작아질수록 감소**.
  3. **상피 변화** : **PCCE**(큰 직경, 점차 세포 높이 낮아지고 단순화) → **단층섬모원주상피(simple ciliated columnar)**(작은 직경) → **단층섬모입방상피(simple ciliated cuboidal)**(가장 작은 직경 = **종말세기관지**).
  - **Clara cell(= club cell)** : **단순상피에서 직경이 작아질수록 증가**, **계면활성제(surfactant)** 분비(점액 대신, 점액 분해효소) — goblet cell 대체.
  4. **신경상피체(neuroepithelial bodies, NEB)** : 분비과립 함유 세포집단(**80~100개 세포**), **콜린성 신경종말** 지배, **가스 조성 감지 화학수용기**로 추정, **기도상피 손상 후 재생·복원**에 참여.
  5. **점막고유판에 평활근 + 탄력섬유 많음** : **미주신경(수축 → 직경↓)** / **교감신경(이완 → 직경↑)**.
  - **천식(asthma)** : 세기관지 **평활근 수축 → 호흡곤란** → **교감신경 흥분제(epinephrine)** 사용.

### 6-3. 통로부분 요약표 (교안 "important!") — 시험 최빈출
이미지(교안): `../../images/교안/resp_theory_p48_summary-chart.jpg`

| 부위 | 상피 | 샘(gland) | 연골 | 평활근 |
|---|---|---|---|---|
| Nasal cavity | **PCCE** | **nasal gland(+)** | – | – |
| Nasopharynx | PCCE (+ 일부 중층편평) | + | – | – |
| Larynx | PCCE (일부 부위 중층편평) | **laryngeal gland(+)** | 유리연골 + 탄력연골 | – |
| **Trachea** | **PCCE** | **tracheal gland(+)** | **C-ring(+)** | **tracheal muscle(+)** |
| **Bronchi** | **PCCE** | **bronchial gland(+)** | **bronchial cartilage(+)** (판·섬) | **bronchial muscle(+, 나선형)** |
| **Bronchiole** | PCCE → **simple ciliated columnar(scce)** | **없음** | **없음** | **+** |
| **Terminal bronchiole** | scce · **simple ciliated cuboidal(sccue)** · simple cuboidal(scue) | 없음 | 없음 | + |
| **Respiratory bronchiole** | **simple cuboidal(scue)** · simple squamous(sse) | 없음 | 없음 | + |
| Alveolar duct | simple squamous | 없음 | 없음 | **knob(sphincter)** |

- 약어 : **pcce** = pseudostratified ciliated columnar epithelium / **scce** = simple ciliated columnar / **sccue** = simple ciliated cuboidal / **scue** = simple cuboidal / **sse** = simple squamous.
- **[보충]** 하행할수록(비강 → 폐포) : **술잔세포 ↓ · 섬모세포 ↓ · 샘 ↓(기관지까지) · 유리연골 ↓(기관지까지) · 평활근 ↑(폐포관까지) · 탄력섬유 지속** — 마지막 도표(p48)의 막대 그래프와 같은 경향.

## 7. 호흡부분(Respiratory portion) — 가스교환
이미지(교안): `../../images/교안/resp_theory_p33_respiratory-bronchiole-diagram.jpg`, `../../images/교안/resp_theory_p34_respiratory-bronchiole-alveolarduct.jpg`

- **구성** : Respiratory bronchioles → Alveolar ducts → Alveolar sacs → Alveoli.

| 구조 | 상피 | 평활근 | 특징 |
|---|---|---|---|
| **1. Respiratory bronchiole(호흡세기관지)** | **Simple cuboidal** — ① **섬모입방세포(ciliated cuboidal cell) & Clara cell** ② **제I형 폐포세포** : **폐포가 열리는 가장자리**에서 관찰 | 있음(상피 아래 평활근·탄력결합조직) | **폐포가 점막으로 열림!!** · 점점 폐포 증가 · 섬모 소실 · 종말세기관지가 **2개의 호흡세기관지로 분지**, 호흡세기관지는 폐포관·많은 폐포로 이어짐 |
| **2. Alveolar duct(폐포관)** | **편평폐포세포(type I, II pneumocytes)** — 벽이 **폐포로만** 구성 | **평활근 섬유다발 = 조임근(sphincter)**, **둥근 덩어리(knob)** 로 보임 | 폐포관 → **폐포방(atrium)** 으로 열림 |
| **3. Alveolar sac(폐포낭)** | simple squamous | **없음** | 폐포방(atrium)과 연결, 모세혈관이 주위에 매우 많음 |
| **4. Alveolus(폐포)** | type I·II | 없음 | **직경 200 μm**, **가스교환(확산 O₂ ↔ CO₂)** 에 특화 |

- 폐포 구성 순서(교안 번호) : 1 Blood vessel · 2 Alveolar sac · 3 Alveolar duct · 4 Alveolus.

### 폐포사이중격(Interalveolar septum) 과 간질(interstitium)
이미지(교안): `../../images/교안/resp_theory_p37_alveolus-diagram.jpg`, `../../images/교안/resp_theory_p38_interalveolar-septum.jpg`

- **두 층의 편평상피 사이** 구조 = **모세혈관 + 결합조직 + 탄력섬유 + 세망섬유**. **평활근 없음**.
- **간질(interstitium)** : **신체에서 모세혈관이 가장 풍부** = 모세혈관 + 결합조직(기질·세포) + **기저막 + 백혈구 + 큰포식세포 + 섬유모세포**.
- **탄력섬유** : 폐포벽이 **팽창/수축**할 수 있게 함 / **세망섬유** : 폐포사이중격 내 **모세혈관을 지지**.

### 폐포벽을 이루는 세포(교안 번호)
이미지(교안): `../../images/교안/resp_theory_p41_type2-cell.jpg`

| 세포 | 특징 |
|---|---|
| **1) 모세혈관 내피세포** | **매우 얇다 → 장벽 두께 최소화** · **핵이 작고 길이가 길다** · **연속형(continuous type), 창(fenestra) 없음** · **포음소포(pinocytotic vesicle)** 풍부 |
| **2) 제I형 세포(Type I, Squamous alveolar cell)** | **폐포 표면의 97%**, **모든 모세혈관을 덮음** · **매우 얇다(25 nm)** → 장벽 최소화 · **세포소기관은 핵 주변부에 집중** · **부착반·폐쇄연접** → 조직액의 폐포 내 유입 방지 · **포음소포 풍부** : 계면활성제 교체, 외부 기원 오염물질 제거 |
| **3) 제II형 세포(Type II, Greater alveolar cell)** | **둥글다**, **폐포벽이 만나는 각 부위에서 2~3개씩** 관찰 · **층판소체(lamellar body)** : **계면활성제 계속 분비·교체** · **분열하여 제I형·제II형 모두 대체 가능(stem cell)** |

- **계면활성제(surfactant)** → **표면장력 감소** → ① **흡기 용이** ② **호기 시 폐포가 서로 달라붙지 않게** 함.
- **줄기세포 자리(stem cell niches, 성체 mouse lung)** : **NEB**(neuroendocrine bodies) · **BADJ**(bronchiolar-alveolar duct junction) 등 — 기도상피 재생에 관여. (교안 p42)

### 혈액-공기장벽(Blood-air barrier)
이미지(교안): `../../images/교안/resp_theory_p43_blood-air-barrier.jpg`

- **정의** : 폐포 안 공기와 모세혈관 혈액을 **분리하는 장벽**. **두께 0.1~1.5 μm**.
- **구성 3가지** : ① **폐포세포(alveolar epithelial cell)** ② **융합된 기저판(fused basal lamina : 폐포세포 + 내피세포)** ③ **내피세포(endothelial cell)의 세포질**.
- **O₂가 적혈구에 도달하기까지 통과하는 구조(순서 암기)** : ① **계면활성제 → ② 폐포상피의 세포질 → ③ 기저판 → ④ 내피세포의 세포질 → ⑤ 혈장** → 적혈구.

### 폐포큰포식세포(Alveolar macrophage = Dust cell)
- **Mononuclear phagocyte system** 소속, **골수 단핵구(monocyte) 기원**. 위치 : **세포사이중격, 폐포 표면 쪽**. 기능 : **먼지(carbon)·세균·기타 입자 제거**(그래서 dust cell).

| **영양혈관(nutrient vessels)** | **체순환** | 폐 조직에 영양 공급(기관지동맥 등 [보충]) |

### 폐의 신경(Pulmonary nerve supply)
- **자율신경(Autonomic)** : 기관지·세기관지에 분포. **부교감(A) 자극 → 폐 평활근 수축 / 교감(B) 자극 → 폐 평활근 이완**.

## Slide #28 — Trachea, Monkey, HE, ×40→×400 — Respiratory epithelium(PCCE)·Tracheal gland·Fibroelastic lamina ★야마
(10/2 노트에서는 **유리연골** 관점으로 작성 → 이번에는 **호흡계통(점막·점막밑층·샘·상피)** 관점으로 새로 정리)
이미지(교안): `../../images/교안/28_trachea_YAMA-respiratory-wall_x40.jpg`, `../../images/교안/28_trachea_YAMA-tracheal-gland-lamina-propria_x100.jpg`, `../../images/교안/28_trachea_YAMA-pcce-goblet-basement-membrane_x400.jpg`

### 조직 소견(야마 우선 서술) [필수]
- ×40 : 안쪽(내강)부터 **PCCE → Lamina propria → Submucosa → T. fibromusculocartilaginea(유리연골 C-ring) → T. adventitia**. 점막이 안쪽, 가운데에 진한 보라색 **유리연골층**.
- ×100 : **PCCE**(섬모가 보이는 상피), 그 아래 **Lamina propria = loose CT**, 그 밑 **Submucosa에 Tracheal gland**(= **compound tubuloalveolar gland**, serous/seromucous), 점막과 연골 사이 **Fibroelastic lamina**.
- ×400 : **Basement membrane**(상피 아래 두꺼운 분홍 띠, 25~40 μm), 상피 사이 **Goblet cell**(점액방울, **HE에서는 잘 염색 안 되어 투명/흰색**, 핵은 아래로 밀려 납작), 상피 속 **Lymphocyte**, 기저 쪽 **Basal cell(작은 둥근 핵)**, 위로 **Ciliated columnar cell(섬모)**.
- 선배 필기 보충 : **ciliated columnar cell은 위가 넓고 아래가 좁은 모양**이라 그 사이에 **basal cell** 핵이 자리, **small granule cell**은 HE에서 구별 어려움.

### 배경설명(정의·분류·기전) [필수]
- **기관 = 통로부분(conducting portion)** — 후두와 기관지를 연결, **C자 유리연골 16~20개**, 뒤쪽 열린 부분은 **trachealis(평활근) + 섬유탄력인대**로 막혀 **내강 과팽창 저항·크기 조절(기침반사)**.
- **점막(T. mucosa) = PCCE + 기저막 + 고유판(loose CT)**
  - **PCCE 5종 세포**(섬모원주세포·술잔세포·솔모양세포·기저세포·소과립세포)는 PART 1-1 표 참고. **섬모세포가 가장 많고 섬모 약 300개**, **술잔세포 = 점액 분비**.
  - **술잔세포 점액 기능** : **glycosaminoglycan(당단백질) 분비 → 호흡상피 방어, 공기 중 독성물질(airborne toxin)이 기관지 내벽으로 들어오지 못하게** 함. **기저세포 = 줄기(progenitor) 세포**, **소과립세포 = 내분비(DNES)**.
  - **기저막(basement membrane)** : 25~40 μm로 **일반 basal lamina보다 훨씬 두껍고 collagen I 풍부** → 외부 물질 유입 방어. **흡연·자극(매연)** 시 **PCCE가 점차 중층편평상피로 변태 → 방어기능 저하**, 만성 기침에서 더 두꺼워짐.
  - **PCCE 내 림프구** : 외부에서 오는 물질에 대한 **방어작용**.
- **점막밑층(submucosa)** : **Seromucous(tracheal) gland** 에서도 점액 분비 → **술잔세포 + 샘 → 점액층 형성**.
- **점액섬모 청소(mucociliary clearance)** : 이물질이 점액층에 붙음 → **섬모운동으로 밖으로 배출(인두 → 삼킴/기침)**. **섬모가 운동하지 않으면 점액이 중력에 의해 흘러내려 폐에 고일 수 있음**(선배 필기).
- **T. adventitia** : 다른 결합조직과 **경계 없이 이어짐**.

| 층(안 → 밖) | 구성 | 핵심 구조 |
|---|---|---|
| T. mucosa | PCCE + basement membrane + lamina propria(loose CT, 림프구) | 술잔세포 · 섬모 · 기저막 |
| Fibroelastic lamina | 탄력섬유 | 점막과 점막밑층 경계 |
| Submucosa | 성긴 결합조직 + **tracheal gland(serous/seromucous)** | 샘 · 혈관 |
| T. fibromusculocartilaginea | **C-ring 유리연골** + trachealis + fibroelastic ligament | 연골(뒤쪽은 평활근) |
| T. adventitia | 결합조직 | 주변과 경계 불명 |

### 암기 포인트
- 기관 = **PCCE + 술잔세포 + tracheal gland(submucosa) + C-ring 유리연골 + trachealis**.
- **기저막 25~40 μm**(두껍다, 흡연 시 ↑) / **술잔세포 + 점액샘 → 점액층 → 섬모운동으로 배출**.
- 기관 vs 기관지 : **C-ring(고리)** ↔ **연골판·섬 + 나선형 평활근 + MALT**.

## Slide #29 — Lung (thin section), Monkey, HE, ×40→×400 — Bronchiole → Alveolar duct → Alveoli ★야마

### 배경설명(정의·분류·기전) [필수]
- **조직 구분 한눈에(통로 → 호흡)**

| 구조 | 상피 | 평활근·연골 | 구분 포인트(선배 필기 포함) |
|---|---|---|---|
| **Bronchiole** | PCCE → simple ciliated columnar → simple ciliated cuboidal | 평활근 O, **연골·샘 X** | 직경 ≤ 1 mm, **submucosa·고유판 거의 없음**, **T. fibromusculocartilaginea에서 연골이 사라지면서 T. muscularis(근육층)** |
| **Terminal bronchiole** | simple ciliated columnar (→ cuboidal) | 평활근 O | **tracheal gland 없음**, goblet cell 거의 없음 |
| **Respiratory bronchiole** | **simple cuboidal** (섬모입방세포 + **Clara cell**) | 평활근 O | **폐포가 점막으로 열림**, 열리는 가장자리에 **type I alveolar cell** |
| **Alveolar duct** | simple squamous (type I·II) | **평활근 knob(sphincter)** | 벽이 폐포로만 구성, 방어작용 없는 시작점 |
| **Alveolar sac** | simple squamous | 평활근 **없음** | 모세혈관 주위 풍부 |
| **Alveolus** | type I · II | 없음 | 200 μm, 가스교환 |

- **구분 기준(선배 필기)** : ① **smooth muscle이 굵은가?** ② **연골이 있는가?** — 연골 없음 + 굵은 평활근 = bronchiole / 평활근이 knob으로 보임 = alveolar duct / 평활근 없음 = alveolar sac.
- **Bronchiole** : 직경 ≤ 1 mm 소엽내 기도. **Clara cell** — 직경이 작아질수록 증가, **계면활성제·mucolytic enzyme 분비**, 신경상피체(NEB)는 **smooth muscle 조절·화학수용기·기도상피 재생**. 점막고유판 평활근·탄력섬유(**미주신경 수축 / 교감신경 이완**). **천식** = 평활근 수축 → 호흡곤란 → epinephrine.
- **Respiratory bronchiole** : 호흡 가능한 첫 구역(폐포가 점막으로 열림), **goblet cell 거의 없음**, 대신 **Clara cell(계면활성제 분비)**.
- **Alveolar duct / sac** : 둥근 평활근 덩어리(knob)는 duct에만 / sac은 평활근 없음, 모세혈관 풍부.
- **폐포사이중격(interalveolar septum)** : 모세혈관 + CT + **탄력섬유(팽창·수축) + 세망섬유(모세혈관 지지)**. 

| 세포 | 위치·모양 | 핵심 |
|---|---|---|
| **Type I pneumocyte** | 폐포 표면 **97%**, 매우 **납작·얇음(25 nm)**, 핵 납작 | 가스교환, **폐쇄연접(occluding junction/tight junction)** → 조직액 유입 방지, **포음소포 많음** → 계면활성제 교체·오염물질 제거 |
| **Type II pneumocyte** | **둥글다**, 폐포벽이 만나는 곳에서 **2~3개씩** | **층판소체(lamellar body)** 에 **surfactant** 저장·분비 → **표면장력 ↓**, **stem cell(분열하여 I형·II형 모두 재생)** |
| **Dust cell(Alveolar macrophage)** | 폐포 표면·세포사이중격, **대체로 움직이지 않음** | **monocyte 기원(Mononuclear phagocyte system)**, 먼지(carbon) 포식 → **검은색 입자** |
| 모세혈관 내피세포 | 폐포 사이 모세혈관 | type I과 비슷해 보이나 **안에 RBC**가 있어 구분 가능, 매우 얇고 핵이 작고 길며 **연속형**, 포음소포 풍부 |

- **혈액-공기장벽** : 계면활성제 → 폐포상피 세포질 → 융합된 기저판 → 내피 세포질 → 혈장(**0.1~1.5 μm**) — PART 1 참고.

### 암기 포인트
- **Terminal bronchiole(simple ciliated columnar, 샘 X) → Respiratory bronchiole(simple cuboidal, 폐포 열림, Clara cell) → Alveolar duct(simple squamous + 평활근 knob) → Alveolar sac(평활근 X)**.
- **Type I = 97% 납작·가스교환 / Type II = 둥글·surfactant·stem cell / Dust cell = monocyte 유래, 검은 먼지**.
- 감별 기준 : **연골 유무 + 평활근 굵기**.

### 선배들 그림
- 선배 오아름(22학번) ×400 (HE) : 라벨 **Type II pneumocyte · Type I pneumocyte · Dust cell**. **Dust cell** = 골수 내 단핵구(monocyte) 기원, 먼지·박테리아·기타 분자 제거, 폐포 표면의 주요 mononuclear phagocyte, 폐포사이중격·폐포 표면에 위치. **Type I** = 폐포 표면의 97%, 혈관과 capillary lumen을 감쌈, 세포질이 얇고 세포소기관이 핵 주변부에 집중되어 장벽 두께를 최소화, 인접세포와 tight junction을 형성해 조직액의 폐포 유입 방지, 포음세포가 활발히 계면활성제를 교체하고 외부기원 오염물질을 제거. **Type II** = 수가 적으며 type I과 달리 둥글다(원문 일부 판독 불확실), type I의 전구세포로 세포분열을 통해 type I·II 모두 regenerate 가능, 둥글며 폐포벽이 만나는 각 부위·모서리 근처에서 2~3개씩 관찰, 계면활성물질을 분비해 폐포를 보호하고 세포질의 lamellar body에 저장. 이미지: `../../images/선배그림/29_lung_YAMA-senior-ahreum_x400.jpg`
- 선배 김은기(23학번) ×20 (HE) : **Bronchiole(세기관지)** = 직경 1 mm 이하, 소엽내기도. 분지에 따라 **PCCE → Simple ciliated columnar E → Simple ciliated cuboidal E**. 신경상피체가 있어 smooth muscle을 조절, 화학수용기 역할, 기도상피세포 재생에 참여. lamina propria에 **평활근과 탄력섬유 많음**(자율신경에 의해 내강 부피 조절). 라벨 : **submucosa 없음 · lamina propria 거의 없음 · T. fibromusculocartilaginea에서 연골이 사라지면서 T. muscularis(근육층)가 됨**. **Terminal bronchiole** : Simple ciliated columnar E., 기관샘이 없음. **Respiratory bronchiole** : 폐포가 점막으로 열림, Simple cuboidal E.로 구성, goblet cell이 거의 없고 대신 **Clara cell이 계면활성제 분비**, 폐포가 열리는 가장자리에서 type I alveolar cell 관찰. **구분 기준 : 1) smooth muscle이 굵은지? 2) 연골이 있는지?** **Alveolar duct** : Simple squamous E.(방어작용은 안 되는 시작점), smooth muscle이 존재하지만 둥근 덩어리(knob)로 나타남. **Alveolar sac** : Simple squamous E., smooth muscle 없음, 모세혈관이 주위에 매우 많이 분포. 이미지: `../../images/선배그림/29_lung_YAMA-senior-eungi_x20.jpg`
- 선배 김은기(23학번) ×264 (HE) : **Alveoli(폐포)** = 주로 simple squamous epithelium으로 구성되어 **기체교환에 유리**. 폐포와 폐포 사이에는 **폐포사이중격**(모세혈관, CT, elastic & reticular fiber)이 존재. **Type I pneumocyte** = 폐포 표면의 97%, 매우 얇고 핵도 납작, 조직액이 폐포로 들어오는 것을 막기 위해 occluding junction 발달, 포음세포가 많아 계면활성제 교체·외부 기원 오염물질 제거, simple squamous E. **Type II pneumocyte** = simple cuboidal E., 계면활성제 분비 및 교체, 자체가 stem cell로 분열하여 I형·II형 모두 대체 가능. **Macrophage(Dust cell)** = 세포사이중격이나 폐포 표면에 존재, 먼지를 처리하여 dust cell, 대체로 움직이지 않음. 이미지: `../../images/선배그림/29_lung_YAMA-senior-eungi_x264.jpg`
- 선배 권영주(22학번) ×200 (thin section) : "연골이 없기에 thin으로 해도 문제 X, 6~10μm". **Dust cell** = 폐포에 있는 대식세포의 특별한 이름, mononuclear phagocyte system, monocyte 기원, 폐포 표면에 존재, remove dust(carbon) → 검은색 먼지를 먹어 검은색으로 보임. **Type I pneumocyte (Sq. alveolar cell)** = 폐포 표면의 97%를 싼다, 매우 얇다, 세포소기관 → 핵 주변부, 폐쇄연접으로 조직액의 유입 X, 포음소포↑ → 계면활성제 교체·외부 기원 오염물질 제거. **Type II pneumocyte (= greater alveolar cell, releasing surfactant)** = 둥글다, 폐포벽이 만나는 각 부위에서 2~3개씩 관찰, **층판소체(lamellar body)** → surfactant 계속 분비·교체, 분열 시 type I·type II 세포 가능, **표면장력 ↓ → 흡기 용이, 폐포가 서로 달라붙지 않도록**. **모세혈관 내피** : type I과 유사해 보일 수 있으나 안의 RBC로 endothelium으로 판단 가능, 매우 얇게 장벽 두께 최소화 → 가스교환, 핵이 작고 길이가 길다, 연속형, 포음소포 풍부. 이미지: `../../images/선배그림/29_lung_YAMA-senior-kwon_x200.jpg`

## 오늘 정리 — 시험 대비 비교 핵심
1. **통로부분 vs 호흡부분** + **통로부분 요약표(상피·샘·연골·평활근)** — 위 PART 1 6-3 표.
2. **기관 vs 기관지 vs 세기관지** : C-ring + tracheal gland / 연골판·섬 + 나선 평활근 + MALT / 연골·샘 없음 + Clara cell.
3. **호흡세기관지 → 폐포관 → 폐포낭 → 폐포** : 폐포가 열림 → 평활근 knob → 평활근 없음.
4. **폐포 세포 3종** : Type I(97%, 가스교환) / Type II(surfactant, stem cell) / Dust cell(monocyte 유래).
5. **혈액-공기장벽** : 계면활성제 → 폐포상피 → 융합 기저판 → 내피 → 혈장(0.1~1.5 μm).
6. **PCCE 5종 세포** : 섬모 / 술잔 / 솔모양 / 기저 / 소과립(DNES).
