# PART 1. Nervous Tissue (신경조직)

## 배경 개념 — 신경계 분류와 구성 (시험 빈출 — 표로 암기)

| 구분 | 세부 |
|---|---|
| 해부학적 분류 | **CNS**(뇌, 척수 — 신경조직 + 결합조직[meninges, choroid plexus]) / **PNS**(신경, 신경절, 신경얼기) |
| 기능적 분류 | Somatic NS / Autonomic NS(교감·부교감) / Enteric NS(소화관) |
| 세포 구성 | **Neuron** + **Neuroglia**, 세포사이물질은 극히 적음 |
| 기능 | 자극 → Receptor → Neuron → Effector 반응 / 흥분성·전도성(전기적: 막·gap junction, 화학적: synapse) |

- **Neuron 기능 분류** : Sensory neuron / Motor neuron(CNS → 근육·샘) / Interneuron(통합, **CNS에만**)
- **Neuron 돌기 수 분류** : unipolar(수상돌기 없음) / **pseudounipolar**(DRG) / bipolar / **multipolar**(대부분, 운동뉴런)

### Neuron 세포체(soma) 구조 [필수]

| 구성 | 특징 |
|---|---|
| 핵 | **Euchromatic**(m-RNA 전사), **핵소체 뚜렷**(r-RNA, ribosome 합성) |
| **Nissl substance** | **r-ER** — 단백질 합성 부위, **염기호성**. **motor neuron에서 잘 발달**, **axon hillock에는 없음** |
| Golgi complex | 핵 주변, 당화·황화·인산화, 단백질 포장·농축 |
| Mitochondria | Na⁺/K⁺ pump, axonal transport 에너지원 |
| 색소과립 | Melanin / **Lipofuscin** |
| 세포골격 | **Neurofilament**(중간섬유, 환원은염색 = neurofibril), Microtubule(tubulin, axonal transport), Actin |

- **Axon에는 단백질 합성 장치가 없다** → soma에서 만든 물질을 **axonal transport**(anterograde: kinesin / retrograde: dynein)로 운반.

### Axon vs Dendrite [필수]

| 구분 | Axon | Dendrite |
|---|---|---|
| 개수 | **1개** | 여러 개 |
| 길이 | 200 μm ~ 1 m | < 700 μm |
| 굵기 | **일정** | **점점 가늘어짐** |
| 분지 | **직각**, 세포체에서 먼 곳 | **예각**, 세포체 가까운 곳 |
| Nissl substance | **없음** | 있을 수 있음 |
| 수초 | 있을 수 있음 | 없음 |
| 전도 방향 | Efferent(soma → 말단) | Afferent(수상돌기 → soma) |

※ 예외 : **pseudounipolar neuron**은 말초돌기(peripheral)가 afferent로 axon 형태.

### Neuroglia (신경아교세포) [필수]

| 위치 | 세포 | 핵·세포 특징 | 기능 |
|---|---|---|---|
| **CNS** | **Astrocyte** | 크고 둥근 타원형 **'potato' 모양** 핵, euchromatin + heterochromatin 반점. **protoplasmic**(gray matter) / **fibrous**(white matter). **GFAP**, perivascular feet | 지지, **BBB 유지·tight junction 유도**, 복구 |
| | **Oligodendrocyte** | **작고 둥근 heterochromatic** 핵, 어두운 세포질 | **CNS 수초 형성**(한 세포가 여러 axon) |
| | **Microglia** | **작고 길쭉**(slender) heterochromatic 핵 | 대식(monocyte 기원, MPS) |
| | **Ependymal cell** | 단층 입방·원주상 상피, 섬모·미세융모 | 뇌실·중심관 내면, **CSF**(choroid plexus) |
| **PNS** | **Schwann cell** | 가늘고 작은 heterochromatic 핵 | **수초 형성**(1 Schwann cell = 1 internodal segment) / 무수신경 감싸기 |
| | **Satellite cell(= Capsular cell)** | 신경절에서 neuron cell body를 둘러싼 **작은 입방~편평 세포** | 미세환경 조절(전기적 절연, 물질 교환) |

- **BBB** : 연속형 모세혈관 내피의 **tight junction** + basal lamina + **astrocyte의 perivascular feet** (유도·유지). MW < 500 Da 물질만 통과.
- **Meninges**(CNS 결합조직) : **Dura mater**(치밀결합조직) / **Arachnoid**(성긴) / **Pia mater**(성긴, 단층편평상피 + 얇은 결합조직)
- **Myelin** : 세포막이 감긴 구조, **Node of Ranvier**에서 도약전도(saltatory). 전도속도 ∝ internodal 길이·수초 두께·axon 직경. (Schmidt-Lanterman cleft)

### 말초신경 결합조직 [필수]

| 층 | 위치 |
|---|---|
| **Endoneurium** | 개별 nerve fiber를 감쌈(속) |
| **Perineurium** | **nerve fiber 다발(fascicle)** 을 감쌈 |
| **Epineurium** | 신경 전체 바깥 — 혈관 포함 |

- Myelinated fiber = Axon + Myelin sheath + Schwann cell / Unmyelinated fiber = Axon + Schwann cell(여러 axon 함께 감쌈)
- 신경 손상 : **Wallerian degeneration**(원위부 anterograde 변성; 수초 붕괴, Schwann cell 증식 → von Büngner's band) / **Axon reaction**(chromatolysis; 핵 편위, Nissl 소실)

## Slide #15 — Spinal cord, Rat, Klüver-Barrera, ×40→×400 — Anterior horn cell ★야마
이미지(교안): `../../images/교안/15_spinalcord_YAMA-kb-overview_x40.jpg`, `../../images/교안/15_spinalcord_YAMA-kb-anteriorhorn_x100.jpg`, `../../images/교안/15_spinalcord_YAMA-kb-anteriorhorncell_x400.jpg`

### 조직 소견(야마 우선 서술) [필수]
- **Klüver-Barrera** = **Luxol fast blue(수초 → 파랑) + Cresyl violet(Nissl → 보라)**. 표본은 척수의 **anterior horn(전각)** 부위.
- ×40 : 안쪽 **Gray matter(회백질)**, 바깥 **White matter(백색질)**, **Anterior / Posterior rootlet**, 가운데 중심관(central canal).
- ×100 : White matter 사이로 Gray matter의 **Anterior horn / Posterior horn**.
- ×400 : **Anterior horn cell = multipolar motor neuron** — 큰 세포체, **핵은 크고 euchromatin(연함)**, **핵소체가 중앙**, 세포질에 **Nissl substance(r-ER, 염기호성)**, 주변 **Neuroglial cell**(astrocyte·microglia·oligodendrocyte·ependymal), **axon**, **Barr body**(heterochromatin = 불활성화된 X 염색체; 여성 세포).
- 염색에서 dendrite는 잘 보이지 않으나 motor neuron이므로 세포체에서 다수의 dendrite가 뻗어 나옴을 유추(선배 필기).

### 배경설명(정의·분류·기전) [필수]
- **Spinal cord 구조** : 중앙 **Gray matter(neuron cell body·soma 집합)** + 바깥 **White matter(수초화된 axon·process 집합, 수초 때문에 White)**. Gray matter는 H(나비) 모양: **전각 = 운동뉴런**, **후각 = 감각 중계(interneuron)**.
- **Anterior horn cell** : 골격근을 지배하는 **α-motor neuron**. 단백질 합성(운동 신경전달물질·효소·막단백) 수요가 커서 **Nissl substance가 특히 잘 발달**.
- **Nissl substance** = **r-ER 덩어리**, basophilic → Cresyl violet(염기성 색소)에 보라색. 합성 부위이므로 axon hillock·axon에는 없다.
- **Barr body** : 여성 체세포에서 보이는 **불활성화된 X 염색체(heterochromatin)**. 호중구의 **drumstick**과 같은 개념(Blood 슬라이드 참조).
- **CNS 구조 보충** : 뇌척수막(**meninges** — dense CT 포함), 뇌척수액을 만드는 **choroid plexus**(ependymal cell + capillary)는 결합조직 성분.

### 암기 포인트
- Spinal cord = **안쪽 Gray(soma) / 바깥 White(axon·수초)**. 전각 = multipolar motor neuron.
- Nissl = r-ER / 핵 = euchromatin + **핵소체 중앙** / Barr body = 불활성 X.
- KB 염색 = **LFB(수초 파랑) + Cresyl violet(Nissl 보라)**.

### 선배들 그림
- 선배 오아름(22학번) ×400 : Nissl substance(평행하게 배열된 r-ER, **양이 많고 basophilic**), **핵(RNA·DNA가 뭉쳐 짙게 염색)** / 핵소체는 리보솜 생성, **Axon**(soma에서 생성된 단백질 사용, r-ER 거의 없음), **Ependymal cell**(뇌척수액 생성, 진정염색질로 이루어져 옅게 염색), Barr body(암컷 세포의 비활성 X 염색체, 빈 공간 안의 염색체). Spinal cord = 안쪽 회백질(cell body)·바깥 백색질(process·axon), 뇌척수막(dense CT)·choroid plexus 설명. 이미지: `../../images/선배그림/15_spinalcord_YAMA-senior-ahreum_x400.jpg`
- 선배 김은기(23학번) ×400 : "Spinal cord 중 **anterior horn** 부위", 주로 **multipolar cell인 motor neuron** 분포, **핵은 euchromatin으로 연하게, nucleolus는 중앙**. **Nissl substance** = basophilic한 r-ER 성분(단백질 생성 특성상 motor neuron에서 잘 발달). 라벨: axon, Barr body, nucleus. **Barr body** = heterochromatin 중 여성에서만 보이는 비활성화된 X 염색체. "염색에서 제대로 보이지 않지만 motor neuron이므로 cell body에서 수많은 dendrite 가지가 빠져나올 것임을 유추". 이미지: `../../images/선배그림/15_spinalcord_YAMA-senior-eungi_x400.jpg`

## Slide #10 — Cerebral cortex, Rat, Ramón y Cajal, ×40→×400 — Astrocyte
이미지(교안): `../../images/교안/10_cerebralcortex_cajal-astrocyte-overview_x40.jpg`, `../../images/교안/10_cerebralcortex_cajal-astrocyte_x100.jpg`, `../../images/교안/10_cerebralcortex_cajal-astrocyte_x400.jpg`

### 조직 소견 [필수]
- **Ramón y Cajal(금 승홍 계열 은·금 침착) 염색**으로 **astrocyte의 세포체와 돌기만 검게** 드러난다(HE에서는 핵만 보임).
- ×400 : **Cell body**에서 뻗은 **다수의 Dendritic(세포질) process**. 별(star) 모양 = astro-cyte.
- 교안 : "Astrocyte — many dendritic processes, exact function not known, supports neurons".

### 배경설명(정의·분류·기전) [필수]
- **분류** : **Protoplasmic astrocyte**(gray matter, 굵고 짧고 가지 많음) / **Fibrous astrocyte**(white matter, 가늘고 길며 섬유성).
- **특징** : **GFAP**(glial fibrillary acidic protein, 중간섬유)가 표지자. **Perivascular feet**(혈관 감쌈), **Perineural feet**.
- **기능** : 신경세포 **지지**, **BBB 형성·유지**(내피 tight junction 유도), 이온·신경전달물질 항상성, 손상 후 **흉터(gliosis)** 형성.
- **특수형** : **Bergmann glia**(소뇌), **Müller cell**(망막), **Pituicyte**(뇌하수체 후엽).
- **[보충]** HE 표본에서는 핵으로 구별 : Astrocyte(크고 둥근 'potato' 핵, euchromatin + heterochromatin 반점) > Oligodendrocyte(작고 둥근 진한 핵) > Microglia(작고 길쭉한 진한 핵) — 아래 #14 참고.

### 암기 포인트
- Cajal 염색 = **astrocyte의 돌기까지 전체 형태**가 보인다. 핵만 보려면 HE(#14).
- Astrocyte = **GFAP / BBB / protoplasmic(gray) – fibrous(white)**.

### 참고 — #14 Medulla oblongata, Rat, HE, ×400 — Neuroglial cell (요청 목록 밖, 사용자 지시로 포함)
이미지(교안): `../../images/교안/14_medulla_neuroglia-nuclei_x400.jpg`
- **핵만 염색된 신경아교세포 감별(교안)** : **Astrocyte** — 크고 둥근/타원형 핵, euchromatic + heterochromatic spot, 감자 모양 / **Oligodendrocyte** — 작고 둥근 heterochromatic 핵, **수초 형성** / **Microglia** — 작고 길쭉한 heterochromatic 핵.
- Medulla oblongata(연수) = CNS 일부, 좌우 신경이 교차하는 부위.

### 선배들 그림 (#14)
- 선배 오아름(22학번) ×400 : 라벨 Neuron / Oligodendrocyte / Astrocyte / Microglia. CNS 신경아교세포 = Astrocyte·Oligodendrocyte·Microglia·Ependymal cell. Astrocyte = 큰 타원형·감자모양 핵, 진정·이질염색질이 모두 있어 진하게/연하게 염색된 부위가 모두 나타남, **GFAP**로 구조 강화되어 **BBB 유지·기능적 제어·수리** 담당, 소뇌의 **Bergmann's glial cell**, 망막의 **Müller cell**, 뇌하수체의 **pituicyte**. Oligodendrocyte = CNS에서 myelin sheath 형성(하나의 세포가 여러 axon을 감쌈), 작은 원형 핵·이질염색질 포함해 검게 염색. Microglia = 작고 납작한 모양, 포식작용, 중배엽 기원. 이미지: `../../images/선배그림/14_medulla_senior-ahreum_x400.jpg`
- 선배 김은기(23학번) ×400 : 라벨 Oligodendrocyte(3) / Microglia / Astrocyte. Medulla oblongata = CNS 일부, 좌우 신경 교차. Oligodendrocyte = 핵이 둥글고 heterochromatic, PNS의 Schwann cell처럼 axon에 myelin 제공, 외배엽 기원. Astrocyte = 핵 크고 둥근 타원형(euchromatic + heterochromatic 둘 다), 별 모양 세포, 신경세포를 붙잡는 역할, 혈관에 붙어 tight junction을 강화하여 **BBB** 형성에 도움. | 특징 | 미성숙 T cell 증식·선택 | **Hassall's corpuscle** |

- **Thymus 특징** : **림프결절·Germinal center가 없다**, **Trabecula 대신 Interlobular septa**(소엽 구조). **신생아에서 크고**, 사춘기 이후 **지방조직으로 퇴축(involution)**. [보충]
- **혈액-흉선 장벽**(cortex 모세혈관 주변 epithelial reticular cell) — 성숙 중인 T cell을 항원으로부터 보호. [보충]
- 감별 : 소엽(lobule) + Hassall's corpuscle = **Thymus**.

### 암기 포인트
- Thymus = **Lobule(Cortex 진 / Medulla 연) + Hassall's corpuscle(medulla)** / **림프결절 없음** / **T cell 성숙**.

- **Monocyte** : **대식세포로 분화**(Mononuclear phagocyte system) — 조직별 이름만 바뀜(CNS = **microglia**, 간 = Kupffer cell 등).
- **Platelet** : **hyalomere**(microtubule, actin·myosin, open canalicular system, dense tubular system) / **granulomere**(**α granule**[fibrinogen·vWF], **δ granule**[Ca²⁺·ATP·ADP·serotonin], **λ granule**[lysosome], mitochondria). 혈액응고 : 혈소판 plug + 응고 cascade(**Hemophilia A = Factor VIII**, B = IX, C = XI).

- 선배 오아름(22학번) ×400 (Wright) : 라벨 Basophil(호염기성 백혈구) / Neutrophil(호중성 백혈구, **Barr body = Drumstick**) / Lymphocyte / Monocyte / Eosinophil. WBC = 세포질 내 과립의 유무와 핵의 모양에 따라 분류. **Granulocyte**(과립 O) — Neutrophil : 전체 WBC 중 가장 양이 많고, 2~5개의 핵엽이 서로 연결된 핵, lysozyme·lactoferrin을 가져 포식작용 가능 / Eosinophil : 2개의 엽으로 구성된 핵, 크기가 크고 기생충 감염 시 그 수가 늚, specific granule에 internum과 externum(괄호 내 "(헤파린·히스타민)" 표기는 판독 불확실 — 교안 기준 internum = MBP 등) / Basophil : 하나의 S자형 핵, IgE 수용체를 가져 알레르기 반응에 관여. **Agranulocyte**(과립 X) — Lymphocyte : 세포질이 매우 적어 핵이 세포의 대부분, 미토콘드리아·r-ER·골지가 적다, 면역반응에 관여(분화하여 B cell·T cell) / Monocyte : 타원형 핵이 옅게 염색, WBC 중 가장 크고 2개의 핵소체, r-ER 적고 미토콘드리아·리소좀이 많음, 분화하면 대식세포. 이미지: `../../images/선배그림/Blood_human_YAMA-senior-ahreum_x400.jpg`
- 선배 김은기(23학번) ×400 (Wright) : 라벨 RBC / N / E / M. **RBC** = 전체 혈액의 44%(Hct), 가운데가 비어 보이는 이유 = 빛이 비치기 때문(**biconcave disk, 2.6 μm / 0.8 μm**), 모양이 다른 RBC가 모이면 **Poikilocytosis**, 크기가 다르면 **Anisocytosis**, **spectrin**으로 모양 유지, **glycophorin**에 붙은 당단백을 antigen으로 가짐(혈액형 결정). **WBC 분류** : Neutrophil·Eosinophil·Basophil = granulocyte, Lymphocyte·Monocyte = agranulocyte. 둘 다 azurophilic granule을 가지지만 **specific granule을 가지는 것은 granulocyte뿐**. **N** : 핵은 2~5개 lobe가 핵사로 연결, 여성의 경우 inactive X chromosome인 **Barr body** 관찰 가능, granulocyte 중 가장 많고 **diapedesis** 시 가장 많이 빠져나감. **E** : 핵은 2개의 lobe, "Allergy reaction 시 B cell과 함께 작용"(원문 그대로, 교안은 allergy·parasite). **M** : 타원형 핵, 미토콘드리아와 리소좀이 잘 발달해 세포질이 basophilic, macrophage로 분화할 시 **Mononuclear phagocyte system**에 의해 이름만 바뀜(예 : CNS의 microglia). **관찰되지 않은 WBC** — Basophil : 전체 WBC의 약 1%, 핵과 granule이 모두 basophilic해 구분이 어렵다, IgE를 가지며 **I형 과민반응**에 mast cell처럼 반응(heparin·histamine 보유), Lymphocyte : 면역 과정에 작용하는 세포, B cell·T cell·Null cell. 이미지: `../../images/선배그림/Blood_human_YAMA-senior-eungi_x400.jpg`

## 조혈(Hematopoiesis) — #82 Bone marrow (observe) [필수·보충]
이미지(교안): `../../images/교안/82_bonemarrow_hematopoiesis_x400.jpg`, `../../images/교안/82_bonemarrow_erythropoiesis_x1000.jpg`, `../../images/교안/82_bonemarrow_granulopoiesis-1_x1000.jpg`, `../../images/교안/82_bonemarrow_granulopoiesis-2_x1000.jpg`

### 조직 소견 [필수]
- **#82 Bone marrow (observe), ×400** : 여러 성숙 단계의 세포가 섞여 있음 — 교안 라벨 **Orthochromatophilic erythroblast, Band cell(다수), Neutrophilic myelocyte·metamyelocyte, Promyelocyte, Mature neutrophil**.
- **Erythropoiesis ×1000** : 1 Proerythroblast(핵 옅고 세포질 호염기성) → 2 Basophilic erythroblast(핵 진해짐) → 3 Polychromatophilic erythroblast(다염색성) → 4 Orthochromatic erythroblast(세포질 분홍, ribosome 사라져 보라색 없어짐) → Reticulocyte → Erythrocyte.
- **Granulopoiesis(neutrophil)** : 1 Myeloblast → 2 Promyelocyte → 3 Neutrophilic myelocyte → 4 Metamyelocyte → 5 Band cell → 6 Mature neutrophil.

### 배경설명(정의·분류·기전) [필수]
- **태생기 조혈** : **Mesoblastic phase**(2주, 난황낭 blood island) → **Hepatic phase**(6주, 간: RBC·백혈구 8주·혈소판) → **Splenic phase**(3개월, RBC) → **Myeloid phase**(6개월~, 골수: RBC·granulocyte·monocyte·platelet) / 림프절: lymphocyte. **Red marrow(조혈)** ↔ **Yellow marrow(지방)**.
- **조혈 계열** : Erythropoiesis / Granulopoiesis / Lymphopoiesis(Lymphoblast → Prolymphocyte → Lymphocyte) / Monocytopoiesis(Monoblast → Promonocyte → Monocyte) / Megakaryocytopoiesis(Megakaryoblast → Megakaryocyte → **Platelet, 10일**).
- **성숙 경향(공통)** : 세포 크기 **작아짐**, **핵 작아지고 농축(pyknosis/segmentation)**, 세포질 소기관 소실. **Erythroid** : ribosome 多(염기호성) → **Hb 형성(호산성)**. **Granulocyte** : **azurophilic granule → specific granule 형성**.
- **Left shift** : band cell 증가 = 감염·염증·빈혈·백혈병.

### 암기 포인트
- **RBC 계열** : Proerythroblast → **Baso → Polychromatophilic → Ortho** erythroblast → Reticulocyte (핵 소실).
- **호중구 계열** : Myeloblast → Promyelocyte → Myelocyte → Metamyelocyte → **Band** → Mature.
