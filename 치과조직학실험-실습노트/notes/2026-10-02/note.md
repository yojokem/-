# PART 1. Muscle (근육조직)

## 배경 개념 — 근육 3종 비교 (시험 빈출 — 반드시 표로 암기)

| 구분 | Skeletal muscle | Cardiac muscle | Smooth muscle |
|---|---|---|---|
| 줄무늬(striation) | 있음 | 있음 | **없음** |
| 수의/불수의 | 수의(voluntary) | 불수의(involuntary) | 불수의(involuntary) |
| 핵 | **다핵**, 세포 가장자리(peripheral) | **1~2개, 중심(central)** | **1개, 중심(central)** |
| 세포 형태 | 길고 원통형(최대 50cm), 직경 30~150μm | 원통형·분지, 직경 ~15μm / 길이 ~80μm | 방추형(fusiform), 길이 20~500μm / 직경 5~10μm |
| 세포 형성 | 수백 개 myoblast 융합 → myotube | 융합 없음 | 융합 없음 |
| 세포 간 연결 | — | **Intercalated disk** (desmosome·fascia adherens·gap junction) | Gap junction 다수(single-unit) |
| T-tubule / SR | T-tubule + 2 terminal cisternae = **Triad** | 굵은 T-tubule, SR 적고 작음 → **Diad** | T-tubule 없음, **Caveola** |
| Ca²⁺ 수용 단백질 | Troponin(TnC) | Troponin | **Calmodulin**(troponin 없음) |
| 위치 | 골격에 부착 | 심장 | 속 빈 장기·혈관벽·호흡기·소화관·생식관·요관·방광·진피 |

## 배경 개념 — 골격근의 결합조직 (#7의 Endomysium / Perimysium 해석용)

| 막 | 위치 | 구성 |
|---|---|---|
| Epimysium (근육바깥막) | 근육 전체 | 치밀 불규칙 결합조직(collagenous) |
| Perimysium (근다발막) | 근다발(fascicle) | 덜 치밀한 불규칙 결합조직(collagenous) |
| Endomysium (근섬유막) | 개별 근섬유 | Reticular fiber + basal lamina |

- 계층: myofilament → myofibril → **muscle fiber(=muscle cell)** → muscle fascicle(bundle) → muscle(예: biceps brachii)
- 근육-뼈 부착 : Direct 또는 Indirect(힘줄·널힘줄 경유). Myotendinous junction = actin filament–linker protein–integrin–basal lamina(laminin–entactin–type IV collagen)–reticular fiber–건/널힘줄의 collagen fiber–(골막 collagen)–Sharpey's fiber–bone matrix.

## Slide #7 — Skeletal muscle, Rat, Modified Gomori trichrome, ×40→×400 — Neuromuscular spindle (신경근육방추)

이미지(교안): `../../images/교안/7_nmspindle_gomori-overview_x40.jpg`, `../../images/교안/7_nmspindle_gomori-overview_x100.jpg`, `../../images/교안/7_nmspindle_gomori-intrafusal-extrafusal_x400.jpg`

### 조직 소견 [필수]
- Modified Gomori trichrome 염색상 골격근 섬유 단면은 **청록색**의 큰 다각형 profile로 보이고, 그 사이를 Endomysium(근섬유막)·Perimysium(근다발막)의 결합조직이 가늘게 가른다. (교안 라벨: ×100 — Endomysium, Perimysium)
- ×400: 큰 **Extrafusal muscle fiber** 사이에 결합조직 capsule로 싸인 작은 원형 구조가 **Neuromuscular spindle** — 내부에 가는 **Intrafusal muscle fiber** 다발과 신경 단면(보라색 핵)이 보인다. (교안 라벨: Intrafusal / Extrafusal muscle fiber, Perimysium, Endomysium)
- 감별 : Extrafusal fiber = 굵고 많은 일반 근섬유 / Intrafusal fiber = spindle 안쪽의 가늘고 적은 근섬유.

### 배경설명(정의·분류·기전) [필수]
- **정의** : Neuromuscular spindle(muscle spindle)은 근육 길이의 변화와 그 변화 속도(빠른지 느린지)를 계속 감시하는 **고유감각수용기(proprioceptor)**. 근섬유 사이에 위치하는 피낭 감각기관(encapsulated sensory receptor).
- **구조(암기)**
  - Capsule(외층·내층) + fluid(GAG 풍부, 현미경상 빈 공간처럼 보임)
  - **Intrafusal fiber** 약 8~10개 : **Nuclear bag fiber**(static / dynamic) + **Nuclear chain fiber**
  - 신경 : 감각신경(**Ia, II**) + 운동신경(**γ-motor**)
  - 모양이 방추형(fusiform = spindle shape)이라 이름이 붙음.
- **Stretch reflex(신장반사, 예: 무릎반사 patellar reflex)** : 근육 신장 → intrafusal fiber 신장 → 감각신경 말단(Ia, II) 자극 → 후근신경절(dorsal root ganglion) → 척수 interneuron → 척수 **α-motor neuron** → **extrafusal fiber 수축**.
- **Golgi tendon organ과 비교**

| 구분 | Muscle spindle | Golgi tendon organ |
|---|---|---|
| 위치 | 근섬유 사이 | 건(tendon)의 collagen fiber 사이 |
| 감지 | 근육 **길이** 변화·속도 | 건의 **장력(tension)** |
| 신경 | Ia, II (감각) + γ (운동) | **Ib** |
| 반사 | Stretch reflex → 수축 | Golgi tendon reflex(=inverse stretch reflex) → α-motor neuron 억제 → **이완** |

- **[보충] 임상 연관** : Exercise-related muscle cramps(ERMC)는 신경-근 반사궁 오류 — Golgi tendon organ은 억제되고 muscle spindle은 과활성되는 상태(교안 기재).

### 암기 포인트
- spindle = **intrafusal(안, 얇음) vs extrafusal(밖, 굵음)** / nuclear bag·chain / Ia·II(감각), γ(운동).
- Muscle spindle = 길이, Golgi tendon organ = 장력(Ib).

## Slide #58 — Uterus, Human, HE, ×40→×400 — Smooth muscle (평활근)

이미지(교안): `../../images/교안/58_uterus_smoothmuscle-wall_x40.jpg`, `../../images/교안/58_uterus_smoothmuscle-myometrium_x100.jpg`, `../../images/교안/58_uterus_smoothmuscle-cross-longitudinal_x400.jpg`

### 조직 소견 [필수]
- ×40 : 자궁벽 3층 — **Endometrium(자궁내막) / Myometrium(자궁근육층) / Perimetrium(자궁외막)**. 표본 대부분을 차지하는 두꺼운 분홍색 층이 Myometrium(평활근).
- ×100 : Myometrium 내 **BV(혈관)** 가 보이고, 평활근 다발이 서로 다른 방향으로 엇갈려 배열(줄무늬 없음).
- ×400 : 같은 시야에서 **횡단(Cross sectioned)** 과 **종단(Longitudinally sectioned)** 이 공존 — 횡단에서는 둥근 profile과 중심의 둥근 핵, 종단에서는 가늘고 긴 방추형 세포와 길쭉한(시가형) 핵이 관찰된다. **줄무늬(striation) 없음**, 핵은 중심.
- (참고 교안 #57 Uterus, monkey, HE는 같은 3층 구조를 보여주는 저배율 예시)

### 배경설명(정의·분류·기전) [필수]
- **정의/형태** : 방추형(fusiform, 양끝이 뾰족하게 taper), 길이 20~500μm / 직경 5~10μm, **중심 핵 1개**, **줄무늬 없음**(actin·myosin filament가 불규칙하게 배열되어 myofibril 없음). Basal lamina + reticular fiber가 둘러쌈. **세포분열 가능**.
- **분포** : 속 빈 장기 벽, 혈관, 복합샘, 호흡기, 피부 진피, 소화관, 생식관, 요관·방광.
- **구조적 특징**
  - Gap junction 다수 / **T-tubule 없음 → Caveola(e)** / **Dense body**(α-actinin 풍부 전자밀집 구조; 세포질 내·세포막 위(desmosome 유사)에 있으며 actin filament·intermediate filament가 부착)
- **분류**

| 구분 | Single-unit smooth muscle (흔함) | Multiunit smooth muscle |
|---|---|---|
| 신경 지배 | 일부 세포에만 | 세포마다 신경섬유 하나씩 |
| 세포 연결 | Gap junction 다수 | 독립된 개별 세포 |
| 수축 양상 | 파동 수축(**연동운동 peristalsis**) | 개별 구조물을 따로 조절 |

- **수축 기전(순서 암기)** : 세포질로 Ca²⁺ 유리 → Ca²⁺이 **Calmodulin**에 결합 → Calmodulin이 Caldesmon에 결합, **myosin light chain kinase(MLCK)** 활성화 → Caldesmon·myosin filament 구조 변화로 actin의 myosin 결합부위 노출 → myosin head가 actin에 결합 → Pi, ADP 순으로 방출(cross-bridge cycling) → **수축**. ※ **Troponin 없음.**
- **[보충]** 자궁 평활근은 임신 시 세포 비대(hypertrophy)와 증식(hyperplasia)으로 크게 늘어난다.

### 암기 포인트
- 평활근 = **줄무늬 ✕ / 핵 1개·중심 / T-tubule ✕(caveola) / troponin ✕ → calmodulin**.
- 횡단 vs 종단 구분 : 횡단(둥근 단면, 핵 중심) / 종단(방추형, 시가형 핵).

## Slide #73 — Heart, Monkey, HE, ×40→×400 — Cardiac muscle (심장근)

이미지(교안): `../../images/교안/73_heart_cardiacmuscle-wall_x40.jpg`, `../../images/교안/73_heart_cardiacmuscle-myocardium_x100.jpg`, `../../images/교안/73_heart_cardiacmuscle-longitudinal-intercalateddisk_x400.jpg`, `../../images/교안/73_heart_cardiacmuscle-cross-centralnucleus_x400.jpg`

### 조직 소견 [필수]
- ×40 : 심장벽 3층 — **Endocardium(심장내막) / Myocardium(심장근육층) / Pericardium(심장막)**.
- ×100 : Myocardium — 심근섬유 다발 사이로 **Connective tissue**(가는 결합조직)가 지나감.
- ×400 종단(longitudinal) : **줄무늬** 있는 원통형 세포, **핵 1~2개가 세포 중심**에 위치, 인접 세포를 잇는 **사이원반(Intercalated disk)** 이 짙은 가로선(계단상)으로 관찰.
- ×400 횡단(cross) : **핵이 세포 중심(Nucleus in the center)** — 핵 주위가 밝게 보이는 halo(미토콘드리아 풍부).

### 배경설명(정의·분류·기전) [필수]
- **정의/형태** : 세포 직경 ~15μm, 길이 ~80μm, **핵 1~2개·중심**, 줄무늬 있음, 분지, Basal lamina + reticular fiber, 혈관 풍부, myoglobin·glycogen 풍부, **미토콘드리아 풍부(핵 주위 halo)**. 세포 융합 없이 형성(골격근과 다름).
- **T-tubule / SR** : T-tubule가 **굵고**, SR은 적고 작음 → 한 개의 T-tubule + 한 개의 terminal cisterna로 이루어진 **Diad**(골격근의 Triad와 다름).
- **Intercalated disk(사이원반)** : 세포가 끝과 끝으로 연결되는 부위

| 부분 | 위치 | 연결 구조 |
|---|---|---|
| Transverse portion (가로부분) | 세포 길이 방향에 수직 | **Desmosome, Fascia adherens** (기계적 결합) |
| Lateral portion (세로부분) | 세포 길이 방향에 평행 | **Gap junction** (전기적 연결) |

- **골격근 vs 심장근 비교(핵·T-tubule·SR·미토콘드리아)**

| 구분 | Skeletal | Cardiac |
|---|---|---|
| 핵 | 다핵, 가장자리 | 1~2개, 중심 |
| T-tubule | 가늘다 → **Triad** | 굵다 → **Diad** |
| SR | 발달 | 적고 작음 |
| 미토콘드리아 | 보통 | 풍부 |
| 세포 연결 | 없음 | 사이원반 |
| 형성 | myoblast 융합 | 융합 없음 |

### 암기 포인트
- 심장근 = **줄무늬 ○ / 중심 핵 1~2개 / 사이원반(desmosome·fascia adherens·gap junction) / Diad / 불수의**.
- 사이원반 : **가로=desmosome+fascia adherens, 세로=gap junction**.

## Slide #19 — Heart, Dog, HE, ×40→×400 — Purkinje fiber (푸르키네 섬유)

이미지(교안): `../../images/교안/19_heart_purkinjefiber-overview_x40.jpg`, `../../images/교안/19_heart_purkinjefiber-endocardium_x100.jpg`, `../../images/교안/19_heart_purkinjefiber-cell_x400.jpg`

### 조직 소견 [필수]
- ×40 / ×100 : **Endocardium(심장내막)** 바로 아래 층에 Purkinje fiber 무리가 있고, 그 아래에 **Myocardium(심장근육층)**. (교안 라벨: Endocardium, Myocardium)
- ×400 : **Purkinje fiber** 는 주변의 일반 **Cardiac muscle fiber** 보다 **크고**, 세포질이 **옅게(pale)** 염색된다(glycogen 풍부). 핵은 1~2개 중심, 근원섬유가 적어 **줄무늬가 약하다**.
- 층 구분(교안 라벨) : Endocardium = **Endothelium → Subendothelial layer → Subendocardial layer(= Purkinje fiber가 위치)**, 그 아래 Myocardium.

### 배경설명(정의·분류·기전) [필수]
- **정의** : 심방·심실벽의 endocardium 쪽에 있는, **크게 특수화된 심근세포** — 전기 자극을 일반 심근세포로 **전도(conduct)** 하는 것이 기능.
- **형태** : 핵 1~2개, 세포질 연분홍(**glycogen + mitochondria**), 줄무늬 약함(**myofibril 빈약**), 세포 연결은 사이원반(gap junction + desmosome).
- **자극 발생·전도계(암기 순서)**

| 순서 | 구조 | 특징 |
|---|---|---|
| 1 | **SA node(동방결절)** | 심박동의 **pacemaker**, 강하게 수축하지는 않음 |
| 2 | **AV node(방실결절)** | 심방과 심실 사이 |
| 3 | **AV bundle(= bundle of His)** | AV node에서 심실중격으로 뻗는 전도조직 띠 |
| 4 | **Purkinje fibers** | **endocardium** 아래, 심실근으로 자극 전달 |

- **Purkinje fiber vs Cardiac muscle fiber**

| 구분 | Purkinje fiber | Cardiac muscle fiber |
|---|---|---|
| 크기 | **더 큼** | 상대적으로 작음 |
| 세포질 | **옅은 분홍, glycogen 풍부** | 호산성(근원섬유 풍부) |
| 줄무늬 | 약함(근원섬유 빈약) | 뚜렷 |
| 위치 | **Endocardium 쪽(subendocardial layer)** | Myocardium |
| 기능 | 자극 **전도** | **수축** |

- **[보충]** 개·소·양 등에서 Purkinje fiber가 특히 뚜렷하여 이 표본(dog)이 쓰인다.

### 암기 포인트
- Purkinje fiber = **endocardium 쪽 / 일반 심근보다 큼 / 세포질 pale(glycogen) / 줄무늬 약함 / 자극 전도**.
- 전도계 순서 : **SA node → AV node → AV bundle(His) → Purkinje fiber**.

# PART 2. Cartilage (연골)

## 배경 개념 — 연골 3종 비교 (시험 빈출 — 반드시 표로 암기)

| 구분 | Hyaline cartilage (유리연골) | Elastic cartilage (탄력연골) | Fibrocartilage (섬유연골) |
|---|---|---|---|
| 섬유 | **Type II collagen** (건조중량의 40%) | Type II collagen + **Elastic fiber** | **Type I collagen** (+ type II) |
| 기질 염색 | 호염기성(basophilic) | (노란빛, 불투명) | **호산성(acidophilic)** |
| 연골세포 배열 | 집단(group) | 많은 세포 / 적은 기질 | 콜라겐 다발 사이 **평행한 줄(rows)** |
| Perichondrium | 있음 (관절연골·epiphysis 제외) | 있음 | **없음** |

| 실습 슬라이드 | **#28 Trachea** | #76 Larynx (교안 포함, 이번 요청 범위 외) | **#5 Intervertebral disc** |

## 배경 개념 — 연골 공통 특징
- 특수결합조직 · 기원 = **미분화 중간엽세포(mesenchymal cell)** · 기능 : 단단한 지지, 젤 같은 충격 흡수, 매끄러운 관절면, 긴뼈 형성.
- **혈관·신경·림프관이 없다** → 영양은 기질 내 수분을 통한 **확산(diffusion)**. 수분 75%(생체 중량).
- **Perichondrium(연골막)** (섬유연골 제외) : 바깥 **fibrous layer**(fibroblast, type I collagen, 혈관) + 안쪽 **cellular layer**(chondrogenic cell). 치밀결합조직, 연골에 영양 공급.
- **연골 세포 3단계**

| 세포 | 특징 |
|---|---|
| **Chondrogenic cell** | 중간엽 유래, 방추형, 난원형 핵·핵소 1~2개, 세포질 적음 → chondroblast 또는 osteoprogenitor cell로 분화 |
| **Chondroblast** | 풍만한 호염기성, rER·Golgi·미토콘드리아·분비소포 발달 |
| **Chondrocyte** | lacuna 속 chondroblast, 난원~원형, 큰 핵·뚜렷한 핵소, 분열하여 **Isogenous cell group** 형성 |

- **성장** : **Interstitial growth**(내부에서 분열·기질 분비로 팽창, epiphyseal plate 등) / **Appositional growth**(perichondrium에서 바깥쪽으로 덧붙임).

## Slide #28 — Trachea, Monkey, HE, ×40→×400 — Hyaline cartilage (유리연골)

이미지(교안): `../../images/교안/28_trachea_hyalinecartilage-stereo_whole.jpg`, `../../images/교안/28_trachea_hyalinecartilage-wall_x40.jpg`, `../../images/교안/28_trachea_hyalinecartilage-perichondrium_x100.jpg`, `../../images/교안/28_trachea_hyalinecartilage-isogenousgroup_x400.jpg`

### 조직 소견 [필수]
- 실체현미경(Stereomicroscopic view) : 기관 단면에서 짙은 청보라색 **C자형 hyaline cartilage ring** 이 관찰.
- ×40 : 기관벽 층 구조 — **T(unica) mucosa → T. submucosa → Cartilage layer → T. adventitia**.
- ×100 : **Cartilage matrix** 양쪽 가장자리에 **Perichondrium**(TS = submucosa 쪽, TA = adventitia 쪽에서 맞닿음). 기질은 호염기성이며 **Territorial matrix(세포영역기질, 진하게 염색)** 와 **Interterritorial matrix(영역사이기질, 연하게 염색)** 구분.
- ×400 : **Chondrocyte(연골세포)** 가 **Lacuna(연골소강)** 속에 위치, 2~수 개가 모인 **Isogenous cell group(동형세포집단 = chondrocyte의 집합)**. 세포 주위의 진한 기질 = Territorial matrix.

### 배경설명(정의·분류·기전) [필수]
- **정의** : Hyaline cartilage = **Type II collagen**(+ type IX, X, XI) fibril이 ground substance와 **굴절률이 같아** 현미경상 섬유가 보이지 않는 **푸른빛 도는 흰색·투명한** 연골.
- **ECM 구성**
  - Ground substance : **Proteoglycan(특히 aggrecan)** = core protein + GAG(**chondroitin 4-sulfate, chondroitin 6-sulfate, keratan sulfate**) / **Hyaluronic acid**(1개에 약 200개의 proteoglycan 결합) / Glycoprotein **chondronectin**(type II collagen, C4S, C6S, HA, integrin에 결합).
  - 기질 구역 분류(**암기**)

| 구역 | 특징 |
|---|---|
| **Pericellular (capsular) matrix** | Type VI collagen, integrin으로 세포가 기질에 부착 |
| **Territorial matrix** | 세포 주위 ~50μm 띠, **chondroitin sulfate 풍부·collagen 빈약** → 호염기성 진함 |
| **Interterritorial matrix** | **Type II collagen 풍부·proteoglycan 빈약** → 연하게 염색 |

- **발생·성장** : 중간엽세포 증식·응축 → chondrification center → 분화 → 기질 분비. 성장은 interstitial(내부) + appositional(perichondrium).
- **분포** : 관절끝, 코, 후두, 기관, 기관지, 갈비뼈 복측끝.
- **[보충]** 기관의 C자형 연골 고리가 열린 후방은 평활근(trachealis)과 결합조직이 막는다.
- 연골 공통 특징·세포 3단계는 위 "PART 2 배경 개념" 표 참고.

### 암기 포인트
- Hyaline = **Type II collagen, 호염기성 기질, perichondrium 있음, 무혈관**.
- **Territorial(진함, CS 풍부) vs Interterritorial(연함, type II collagen 풍부)** 구분.
- Isogenous cell group = 한 chondrocyte가 분열해 생긴 세포군.

# PART 3. Bone (뼈)

## 배경 개념 — 뼈 일반

- **정의** : ECM에 **무기질이 많은 특수결합조직**. 기능 — 골격 형성, 장기 보호, **Ca²⁺ 농도 조절(체내 Ca²⁺의 99% 저장)**, 조혈(bone marrow).
- **구성** : Osteoblast(뼈모세포; 기질 합성) / Osteocyte(뼈세포; 기질에 갇혀 합성능을 잃은 세포) / Osteoclast(뼈파괴세포; 뼈 용해·흡수) / **Bone matrix(뼈기질) = 무기질 + Type I collagen + 무형질**.
- **형태 분류(육안)** : **Compact bone(치밀뼈)** — 단단, 하중 지지 / **Spongy(cancellous) bone(해면뼈)** — 다공성, marrow cavity, trabeculae, 가벼움.
- **성숙도 분류(현미경)**

| 구분 | Primary bone (woven bone) | Secondary bone (lamellar bone) |
|---|---|---|
| 성숙도 | 미성숙 | 성숙 |
| 특징 | 세포 많음, 섬유다발 불규칙, 광화 적음 | **Lamellae(3~7μm)**, **Canaliculi**, 더 많이 석회화, collagen이 규칙적·평행 |
| 출현 | 발생 중·골절 치유 | 성인 뼈 |

- **Periosteum(골막)** : 바깥 **fibrous layer**(치밀 불규칙 결합조직, fibroblast, 신경, 혈관) + 안쪽 **cellular layer**(osteoprogenitor cell, osteoblast, osteoclast), **Sharpey's fiber**로 뼈에 고정. **Endosteum(골내막)** : 치밀뼈 안쪽 면·trabeculae를 덮고 osteoprogenitor/osteoblast/osteoclast 보유.
- **탈회(Decalcification) 필요** : 일반 조직표본은 탈회(예: #3) / 이 실습의 **#2 는 연마표본(ground)** 이라 탈회 없이 무기질이 보존되며 세포·연조직은 소실된다.

## 배경 개념 — 뼈 세포 비교 (시험 빈출)

| 세포 | 기원 | 위치·형태 | 기능·특징 |
|---|---|---|---|
| **Osteoprogenitor cell** | 중간엽 줄기세포 | endosteum·periosteum 안쪽, 방추형, 연한 난원형 핵, 세포질 적음 | Osteoblast(저산소 시 chondroblast, 또한 fibroblast)로 분화 |
| **Osteoblast** | 중간엽세포 | 뼈 표면에 **시트 모양** 배열, 입방~원주형, **호염기성 세포질**, 돌기·gap junction | **Osteoid**(미석회화 뼈기질: type I collagen, proteoglycan(chondroitin sulfate), glycoprotein) 분비, **RANKL** 분비, **PTH 수용체**, OPG 분비 / 비활성형은 납작한 bone lining cell |
| **Osteocyte** | Osteoblast가 기질에 갇힘 | **Lacuna** 속, **납작한 핵·세포질 빈약**, 돌기는 **canaliculi** 속, gap junction | **분열 불가**, 비활성이나 기질의 단백질·무기질 유지·감시, **mechanotransduction**, 손상 뼈 수리 참여 |
| **Osteoclast** | **조혈줄기세포 유래**(교안 기재), 세포 융합 | 직경 ~150μm 대형·불규칙, **다핵(5~50개)**, **호산성 세포질**, **Ruffled border + Clear zone**, **Howship's lacuna(침식소강)** 안에 위치, 떠돌이 세포 | **Collagenase·단백분해효소로 뼈 흡수**, 수용체: **calcitonin, RANK, CSF-1**, **PTH 수용체 없음** |

- **Osteoclast 형성·조절** : **M-CSF**(단핵 osteoclast 전구세포 형성) → **RANKL**(osteoblast가 분비, RANK에 결합 → 다핵 osteoclast 형성) / **OPG**(RANKL에 결합해 신호 억제) / **Calcitonin**(갑상샘 부여포세포, 파골 활성 억제) / **PTH** : osteoclast에는 수용체가 없고 **osteoblast를 자극해 RANKL을 분비**하게 함.
- **Osteoclast의 뼈 흡수** : 무기질 제거(**H⁺-ATPase로 pH 4.0 이하**의 산성 환경) → 유기기질 분해(lysosomal hydrolase, metalloproteinase: collagenase·gelatinase). **Odontoclast** = 유치 치근 흡수와 관련된 osteoclast.

## 배경 개념 — 뼈 발생 2종 비교 (시험 빈출)

| 구분 | Intramembranous ossification (막내골화) | Endochondral ossification (연골내골화) |
|---|---|---|
| 출발 | **중간엽(mesenchyme)** 에서 직접 | **Hyaline cartilage model**이 먼저 생기고 뼈로 치환 |
| 연골 모형 | 없음 | 있음 |
| 대표 부위 | 편평골(머리뼈), 쇄골, **하악체(mandible body)**, 긴뼈의 appositional growth | **긴뼈**, **하악 condyle(관절돌기)** |
| 실습 슬라이드 | **#OH26** (구개골) | **#80** (골단판) |
| 핵심 과정 | 중간엽세포 → osteoblast → osteoid 분비 → 광화 | 연골 석회화 → 연골세포 사멸 → 혈관·osteoprogenitor 침입 → 연골 기질 위에 뼈 형성 |

(참고: 뼈 vs 연골 요약 — 뼈는 혈관·신경·림프관 **있음**, 연골은 **없음** / 뼈는 무기질 67%, 연골은 gel-like / 성장은 뼈·연골 모두 interstitial·appositional / 덮개: 뼈 = periosteum·endosteum, 연골 = perichondrium)

- **정의** : **Osteon(Haversian system)** = 긴뼈 치밀뼈의 **구조 단위**. **원통형·동심원상 lamellae** 가 뼈 장축과 **평행**하게 배열, 중심에 **Haversian canal**(혈관·신경). Lamellae는 뼈의 강도를 높임.
- **Lamellae 종류(암기)**

| 층판 | 위치 |
|---|---|
| **Concentric lamellae(Osteon)** | Haversian canal 주위 동심원 |
| **Circumferential lamellae** | 뼈 **바깥(outer)** 과 **안쪽(inner)** 표면을 둘러쌈 |
| **Interstitial lamellae** | Osteon 사이 빈 공간을 채우는 오래된 osteon의 잔여 |

- **통로 구분** : **Haversian canal** = 뼈 장축과 평행, 혈관·신경 / **Volkmann's canal** = Haversian canal끼리·골막과 **횡(수직)으로 연결**(교안 라벨) / **Canaliculi** = lacuna 사이를 잇는 미세관(osteocyte 돌기가 지나는 통로, 영양·신호 교환).
- 개별 osteocyte는 **lacuna** 안에 위치(mm³당 약 2~3만 개).
- **#3(탈회, HE) vs #2(연마) 비교**

| 구분 | #3 Decalcified bone, HE | #2 Ground bone |
|---|---|---|
| 처리 | 산으로 **탈회** 후 절편·염색 | 무기질 보존, **갈아서** 얇게 연마 |
| 보이는 것 | 세포·기질·골수 | 기질 구조(osteon, lacuna, canaliculi, canal) |
| 세포 | 보임 | 소실 |

### 암기 포인트
- Osteon = **Haversian canal + 동심원 lamellae(+ lacuna·canaliculi)**.
- **Haversian(장축 평행) vs Volkmann(수직 연결)**, interstitial lamella = 오래된 osteon 잔여.
- Ground bone = **세포 없음, 빈 공간(lacuna·canaliculi)만 보임**.

### 조직 소견 [필수]
- ×40 : 구개 단면 — 위쪽 **Oral cavity(구강)**, 가운데 **Palatal bone(구개골)**, 아래 **Nasal cavity(비강)**, 그 사이 **Nasal septum bone**.
- ×100 : 좌우의 **Palatal bone** 두 개가 정중선 쪽으로 자라고 있고, 그 사이 정중선에 아직 뼈가 되지 않은 **Mesenchyme(중간엽)** 이 남아 있다.
- ×400 (osteoid 부위) : 뼈 표면에 **Osteoblast**(입방~원주형, 호염기성 세포가 시트 모양으로 배열, 뼈 형성 중), 그 바로 아래 **Osteoid**(미석회화 기질, 연한 색), 기질 속 **Osteocyte in lacuna**, 안쪽 **Bone matrix**(광화된 짙은 분홍).
- ×400 (osteoclast 부위) : 뼈 표면에서 **Osteoclast** — 크고 **다핵(multinucleated)** 이며, 뼈 표면의 얕은 홈 **Howship's lacunae(침식소강)** 안에 위치. 같은 시야에 **Osteoblast(흔함, 뼈 형성 중)**, **Osteocyte in lacuna**, **Bone matrix**, **Bone marrow** 관찰.

### 배경설명(정의·분류·기전) [필수]
- **정의** : Intramembranous ossification = **중간엽이 연골 단계 없이 직접 뼈로 분화**하는 뼈 형성. 부위 : **편평골(머리뼈·구개골), 쇄골, 하악체**.
- **과정(순서 암기)** : 중간엽세포가 **osteoblast** 로 분화 → osteoblast가 **osteoid** 분비 → osteoid **광화(calcification)** → **Primary ossification center** 형성 → 여러 center의 **융합** → **Woven bone(primary bone)** 형성 → **Periosteum** 형성 → 표면에 **Lamellar bone(성숙 뼈)** 형성.
- **Osteoblast → Osteocyte** : osteoblast가 분비한 기질에 둘러싸이면 osteocyte(lacuna 속)가 되고, 뼈는 osteoid가 광화되며 자란다. 성장은 약 18세(여)·21세(남)까지.
- **광화(mineralization) 기전**
  - **Heterogenous nucleation theory** : collagen fiber 틈(gap)에 calcium phosphate가 침착.
  - **Matrix vesicle theory** : osteoblast가 분비한 100~200nm의 막성 소포(Ca²⁺ 펌프, 고농도 Ca²⁺·PO₄³⁻, alkaline phosphatase, ATPase 등 포함)가 광화의 핵이 됨. 자극 : proteoglycan, Ca-binding glycoprotein(osteonectin, bone sialoprotein).
- **뼈 세포(osteoblast / osteocyte / osteoclast)·분화 조절(M-CSF·RANKL·OPG·PTH·calcitonin)** 은 위 "PART 3 배경 개념 — 뼈 세포 비교" 표 참고.
- **뼈 개조(remodeling) 개요** : Activation & resorption(osteoclast) → Reversal → Bone formation(osteoblast) → Quiescence. (osteoclast의 흡수 소강 = Howship's lacuna)

### 암기 포인트
- 막내골화 = **연골 모형 없이 중간엽 → osteoblast → osteoid → woven bone → lamellar bone**, 대표 부위 **구개골·머리뼈·쇄골·하악체**.
- **Osteoblast(표면, 뼈 형성) / Osteoid(미석회화) / Osteocyte(lacuna) / Osteoclast(다핵, Howship's lacuna, 뼈 흡수)** 위치 구분.
- 정중선의 **Mesenchyme** = 아직 뼈가 되지 않은 부분.

## Slide #80 — Bone development, Human, (Azan-)Mallory, ×50→×400 — Endochondral ossification (연골내골화)

이미지(교안): `../../images/교안/80_bonedevelopment_endochondral-stereo_whole.jpg`, `../../images/교안/80_bonedevelopment_endochondral-epiphysealplate_x50.jpg`, `../../images/교안/80_bonedevelopment_endochondral-overview_x100.jpg`, `../../images/교안/80_bonedevelopment_endochondral-reserve-proliferation_x400.jpg`, `../../images/교안/80_bonedevelopment_endochondral-maturation-hypertrophy_x400.jpg`, `../../images/교안/80_bonedevelopment_endochondral-calcification-erosion_x400.jpg`, `../../images/교안/80_bonedevelopment_endochondral-ossification_x400.jpg`

### 조직 소견 [필수]
- **Azan-Mallory 염색(교안)** : **핵 = 빨강(Red), Collagen = 파랑(Blue)**, 뼈는 **초기 = 파랑, 성숙 = 빨강**. (교안 #80 표기는 Azan-Mallory / Mallory 혼용)
- 실체현미경·×50 : 위에서 아래로 **Epiphysis(뼈끝, bone)** → **Epiphyseal plate(뼈끝판, cartilage)** → **Metaphysis(뼈몸통끝)** → **Diaphysis(뼈몸통, endochondral ossification 진행)**.
- ×400 영역별(교안 라벨, 위 → 아래 = 골단판에서 골간 쪽)

| 사진 | 라벨된 구역 |
|---|---|
| ① | **Reserve zone(예비연골구역)** · **Zone of proliferation(증식구역)** |
| ② | **Zone of maturation(성숙연골구역)** · **Zone of hypertrophy(비대연골구역)** · **Zone of calcification(석회화구역)** |
| ③ | **Zone of calcification(석회화구역)** · **Zone of erosion(침식구역)** |
| ④ | **Zone of ossification(뼈형성 구역)** |

### 배경설명(정의·분류·기전) [필수]
- **정의** : Endochondral ossification = **hyaline cartilage model** 이 먼저 만들어지고 그것이 뼈로 **치환**되는 뼈 형성. 부위 : **긴뼈, 하악 condyle**.
- **골단판(epiphyseal plate)의 구역별 변화(암기: 위→아래)**

| 구역 | 세포·기질의 변화 |
|---|---|
| **Reserve (resting) zone — 예비연골구역** | 연골세포가 **불규칙·무작위로 분포**, 휴지 상태 |
| **Zone of proliferation — 증식구역** | 연골세포가 분열해 **Isogenous cell group**(줄지어 쌓인 모양) 형성 |
| **Zone of maturation / hypertrophy — 성숙·비대연골구역** | 연골세포가 성숙·**비대(hypertrophic)**, **glycogen 축적**, 세포 주위 기질은 얇아짐 |
| **Zone of calcification — 석회화구역** | 연골세포 **사멸**, 기질 **석회화** |
| **Zone of erosion — 침식구역** | 석회화 연골 기질이 **파괴·흡수**되고 **혈관·osteoprogenitor cell이 침입** |
| **Zone of ossification — 뼈형성 구역** | 남은 **석회화 연골(scaffold) 위에 osteoblast가 뼈 기질 침착** |

  (이론 교안의 5구역 표기: Reserve → Proliferative → Hypertrophic → Calcified cartilage → Ossification. 실습 교안은 maturation·erosion을 추가해 7구역으로 표기.)
- **염색 소견** : 석회화된 연골(calcified cartilage)은 **파랑**, 석회화된 뼈(calcified bone)는 **빨강**으로 염색되어 **calcified cartilage / calcified bone complex** 를 구분할 수 있다(교안 기재).
- **Endochondral ossification 단계(암기)**
  1. **Hyaline cartilage model** 형성 — 일부 연골세포가 성숙·비대·사멸하고 기질이 석회화.
  2. **Primary center of ossification** — diaphysis 중앙 perichondrium이 혈관화되어 **periosteum** 로 변함 → chondrogenic cell이 osteoprogenitor cell로 → osteoblast가 **Subperiosteal bone collar**(= intramembranous 방식으로 만든 primary bone) 형성.
  3. 골간 중심부 연골세포 비대·사멸 → 큰 공간 형성 → **Osteoclast** 가 bone collar에 구멍을 내 **혈관·osteoprogenitor cell 침입**(osteogenic bud).
  4. 석회화 연골 위에 뼈 기질 침착 → **Calcified cartilage/calcified bone complex** → osteoclast가 흡수해 **marrow cavity** 확장 → bone collar이 epiphysis 쪽으로 성장.
  5. **Secondary center of ossification** — epiphysis에서 시작(bone collar 없이 석회화 연골 위에 osteoblast가 기질 침착).
  6. **Epiphyseal plate에서 성장** — 골단판은 **연골 쪽에서 증식(interstitial growth)**, 골간 쪽에서 뼈로 치환 → 성장 종료 시 골단판 증식이 멈추고 epiphysis와 diaphysis가 **연속**됨.
- **[보충]** 사진 ③·④ 구역은 골단판 쪽에서 골간 쪽으로 이동할수록 연골 기둥이 얇아지고 붉은 뼈 기질이 늘어나는 모양이다.
- **이론 교안 중 이번 요청과 연계되는 기전** : 광화 기전(Heterogenous nucleation / Matrix vesicle), 뼈 개조(remodeling)와 골절 치유(fracture repair)는 위 #OH26 및 이론 교안 105p 참고.

### 암기 포인트
- 구역 순서 : **Reserve → Proliferation → (Maturation/)Hypertrophy → Calcification → (Erosion/)Ossification**.
- **Azan-Mallory : 핵 빨강 / collagen 파랑 / 초기 뼈 파랑 → 성숙 뼈 빨강 / 석회화 연골 파랑 vs 석회화 뼈 빨강**.
- **막내골화 vs 연골내골화**(위 비교표) — "연골 모형 유무"와 "bone collar는 막내골화 방식" 포인트.
