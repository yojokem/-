## p04 _04.jpg  (Kennedy Classification - 전체 표)  [도식, 중요: q04.jpg]
제목: Kenndy Classification (슬라이드 원문 철자 그대로 "Kenndy") / For Partial Edentulous Arches
구조: 좌측 4개 라운드 박스 → 가운데 빨간 세로 화살표 "1st" → 노란 테두리 열(Class I~IV 아치 그림) → 우측 열 Mod 1, Mod 2
좌측 박스 ↔ Class:
- 양측성 → Class I
- 편측성 → Class II
- 전후방 치아 잔존 → Class III
- 정중선 포함 전치 → Class IV
격자(3열 x 4행):
 Class I | Class I Mod 1 | Class I Mod 2
 Class II | Class II Mod 1 | Class II Mod 2
 Class III | Class III Mod 1 | Class III Mod 4   (그림 라벨은 "Mod 4"로 보임)
 Class IV | "No Modification"(빈칸)
(하악 그림: Class I, II 행 / 상악 그림: Class III, IV 행)

## p10 _10.jpg  (Applegate 원칙 1)
Applegate 원칙 / Kennedy classification에 추가적용
▶ 주분류를 변경시킬 수 있는 어떠한 발치도 발치를 시행한 후 분류에 포함
   • 발치 후 분류 (굵게)
▶ 제3대구치가 결손되고 회복시켜 주지 않는 경우에는 분류에 포함시키지 않는다.
   • 사랑니 발치 후 수복 X → 제외 (굵게)
▶ 제3대구치가 존재해 있을 경우, 이것을 지대치로 사용할 때에만 분류에 포함시킨다.
   • 사랑니 지대치 사용 예정 → 포함 (굵게)

## p11 _11.jpg  (Applegate 원칙 2)  [시험 강조: 빨간 글씨]
Applegate 원칙 / Kennedy classification에 추가적용
▶ 제2대구치가 결손되었어도 수복하지 않는다면 분류에 포함하지 않는다.
   • 제2대구치 결손 시 수복 X → 제외
▶ 하나 이상의 결손부위가 있을 때에는 최후방 결손부위(무치악부분)가 항상 주분류를 결정
   • 최후방 결손부위 가 주분류를 결정   (빨간색 강조)
▶ 주분류를 결정하고 남은 다른 결손부위는 modification으로 표시, 그 수만 기록
▶ Modification의 크기와 위치는 고려되지 않으며, 단지 수만 표기
   • mod는 결손치아 갯수 상관 없음, 부위 수로 표기
▶ Class IV는 modification이 없다.   (빨간색 강조)
교수가 스크린 가리키는 사진.
