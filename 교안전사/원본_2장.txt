## p02 KakaoTalk_20260922_061030611_02.jpg  [용어 RPD - Stability]  (이미지: c02.jpg)
제목: 용어 / RPD
좌측 박스(교과서 발췌 이미지, 3개 정의; 본문 글씨는 작아 대부분 판독 불가):
 - 안정(stability): 의치가 견고하고 측방 움직임 없이 항상 안정된 상태로 있으려는 성질 ... [불확실: "성질이며, 기능력, 수평 및 회전 응력에 저항하는 성질로 ... 의치상이 움직임에 대해 저항한다는 것이다" 정도만 흐릿하게 보임]
   (삽화: 사람이 팔짱 끼고 서 있고 다른 사람이 옆에서 미는 그림, 캡션 "안정")
 - 유지(retention): 중력, 음식물의 점착성과 개구 시 수반되는 힘 등 의치가 삽입 방향으로 방향으로 탈락하려는 것에 저항하는 의치에 내재된 성질 [불확실, 부분 판독]  (삽화: 기둥에 매달린 사람, 캡션 "유지")
 - 지지(support): 조직으로 향하는 힘(주로 수직력) 때문에 생기는 보철물의 운동에 대한 저항을 말한다 [부분 판독]  (삽화: 팔을 벌려 천장을 받치는 사람, 캡션 "지지")
우측 도식 "Stability"(노란 라벨): 사다리 -> (빨간 화살표) 의자(벤치) -> (빨간 화살표) 관(coffin) 그림. (사다리가 쓰러지듯 눕는 비유; 이 슬라이드에는 별도 설명 글 없음)

## p07 KakaoTalk_20260922_061030611_07.jpg  [용어 RPD - Clasp 종류]  (이미지: c07.jpg)
제목: 용어 / RPD,  라벨 "Clasp"
좌측 박스(교과서 발췌, 작은 글씨 일부 판독):
 - 유지장치(retainer)는 보철물의 고정이나 안정을 위해 사용되는 모든 종류의 클라스프와 부착형 유지장치(attachment) 및 장치들을 통칭한다 [부분 판독]
 - 클라스프(clasp)는 유지장치, 암(arm) 또는 총체(assembly)같은 용어와 함께 쓸 수 있다. 클라스프 총체(clasp assembly)는 클라스프의 유지암, 보상 혹은 안정암과 주연결장치 및 레스트 등으로 구성된다 [부분 판독] (사진: 클라스프 구강내)
 - 바형 클라스프 암(bar clasp arm)은 의치상이나 금속구조물에서 나와 연조직을 가로질러, 치은 방향에서 치아의 언더컷 부위로 올라가는 치관외 유지 클라스프 장치이다 [부분 판독] (사진: 바형 클라스프)
 - 주연결장치(major connector)는 치열궁 한 쪽 편에 있는 구성요소들과 반대편 구성요소들을 연결해 주는 가철성 국소의치의 한 부분이다 [부분 판독] (사진 2장: 상/하악 주연결장치)
우측 박스: "치관외 유지장치 / 종류"
 - 환상형 클라스프 (Circumferential clasp)
 - 바형 클라스프 (Bar clasp) : 약간 다른 구성요소
 - 조합형 클라스프 (Combination clasp) : 주조 + 합착   [원문 "주조 + 합착" 그대로; 합착은 "wrought wire"(단조선)의 오기일 수도 있으나 슬라이드 표기를 그대로 적음. 교과서상 조합형=주조 + 가공선(wrought wire); 위 p11 표에도 "조합형 -> 가공선" 있음 -> 슬라이드 "합착"은 판독 불확실 가능성]
 하단 이미지 3개: Circumferential clasp / Bar clasp / Combination clasp

 행 "클라스프 설계":
   Tooth supported: 주조 환상형 / 제한된 가요성 / 반원형 형태 -> 지대치에 위해한 외력 / 바형 / 조합형 [부분 판독]
   Tooth-Tissue supported: 환상장치 -> 논란의 여지 존재 / 바형 -> 근심레스트 -> class II lever / 조합형 -> 가공선 (높은 가요성, 조절성, 심미성) / 잔존치조제, 지대치에 전달되는 응력의 양 / 힘의 방향과 크기 / 의치상(지렛 작용)의 길이 / 저항의 점 / 국소의치 설계의 특성 [부분 판독, 세부 불확실]
 행 "간접유지장치":
   Tooth supported: 필요 없음
   Tooth-Tissue supported: 간접유지 장치 필요
 행 "의치상 재료":
   Tooth supported: 금속의치상 / 레진의치상
   Tooth-Tissue supported: 아크릴릭 레진의치상 -> 첨삭 가능 [부분 판독]
