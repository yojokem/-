{B}부분 무치악의 분류{/B}

[학습목표 >>>] (체크박스 3개)
☑ 분류체계의 요구조건을 알 수 있다.

[본문 왼쪽 단]
부분 무치악 상태는 남아있는 자연치아와 결손치아의 수와 위치에 따라 다양한 양상을 보이고 약 65,000 증례의 조합가능성이 있다고 1921년 Dr. W. E. Cummer에 의해 보고되었다. 이와 같이 많고 다양한 부분 무치악 상태를 체계적으로 분류함으로써 그 상태에 대한 임상적 국소의치설계 이론을 정립하고 의사전달과 교육이 이루어질 필요성이 요구되었다.
 이에 많은 학자들이 명확하고 유용한 분류방법을 제창하였는데, Kennedy, Cummer, Bailyn, Beckett, Godfrey, Swenson, Friedman, Skinner, Applegate, Avant, Miller 등의 분류법이 있다.
 많은 분류방법이 제창되었지만 오랜 치과의료 역사에서 널리 사용되고, 추천받고 있는 것은 몇 가지 되지 않는다. 그 중 Kennedy 분류체계가 가장 많이 활용되고 있으며, 세계적으로 가장 널리 사용되어지고 있다.

[본문 오른쪽 단]
{B}I. 분류체계의 요구조건{/B}
 부분 무치악 상태의 분류방안은 다음과 같은 요구조건을 만족해야 한다.
 1. 부분 무치악의 형태를 쉽게 가시화하고 인식할 수 있어야 한다.
 2. 치아지지 상태인지 또는 치아와 조직의 지지상태인지 쉽게 분간할 수 있어야 한다.
 3. 보편적이며 널리 응용될 수 있어야 한다.
 4. 설계의 유형을 제시해 줄 수 있어야 한다.

{B}II. Kennedy 분류법{/B}
 1925년 Dr. Edward Kennedy에 의해 발표된 부분 무치악 분류방법은 일상언어와 같이 치과의료인 사이에

쉽게 의사를 전달할 수 있으며, 거의 모든 무치악 상태에 적용할 수 있다. 단순하고 쉽게 적용할 수 있으며, 중요 설계의 지침을 암시해 줄 수 있다. 또한 이 분류방법은 다양한 설계개념에서도 논리적 접근과 적용이 용이하다. Kennedy는 모든 부분 무치악을 4가지 주분류(basic classes)로 구분하였다. 주분류 이외의 무치악 부위는 추가결손부위(modification space)로 구분하였다.
 다음이 Kennedy 분류법이다(그림 3-1).

 Class I. 양측성 결손부위가 잔존자연치아의 후방에 위치하는 경우
 Class II. 편측성 결손부위가 잔존자연치아의 후방에 위치하는 경우
(→ 오른쪽 단 상단 "에 위치하는 경우"로 이어짐; 왼쪽 단 하단 Class II 항목은 "...잔존자연치아의 후방" 에서 끝나고 오른쪽 단 첫 줄 "에 위치하는 경우"로 이어짐)

[오른쪽 단]
(Class II 항목 이어짐) 에 위치하는 경우
 Class III. 편측결손부위의 전방과 후방에 잔존치아가 모두 있는 경우
 Class IV. 전치부 정중선을 지나 양측을 포함하는 하나의 결손부위가 잔존자연치아의 전방에 위치한 경우

 이 분류에 추가결손부위는 modification(Mod)으로 불렀으며, 추가결손부위를 갯수로만 표기하였다.
 Kennedy 분류법에서 Class I 은 양측성으로 두 개의 무치악부위가 있는 경우이고, Class II는 편측성으로 한 개의 무치악부위가 있는 경우로 초보자이거나 학생
(→ 42쪽 왼쪽 단으로 이어짐)

[그림 3-1: Kennedy 분류법. Kennedy 주분류와 modification 예.]
(캡션: 파란 라벨 "그림 3-1" + "Kennedy 분류법. Kennedy 주분류와 modification 예.")
표 형태의 그림. 3열 x 4행 격자, 각 칸에 치열궁(악궁) 일러스트(하악 궁 + 상악 궁 혼합)와 라벨. 하악 3행(Class I, II 줄)은 아래턱(하악)처럼 보이는 U자 모양, Class III·IV 줄은 상악(구개가 보이는) 모양. 잔존치는 흰 치아, 무치악 부위는 분홍 잇몸으로 표시. 칸 라벨은 이미지 속 글자 그대로:
 1행 (하악 궁): [Class I] [Class I Mod 1] [Class I Mod 2]
   - Class I: 양측 구치부 결손(전치~소구치만 남음, 양측 후방 무치악)
   - Class I Mod 1: 양측 후방 결손에 더해 전치부 쪽 한 곳 추가 결손
   - Class I Mod 2: 양측 후방 결손에 더해 추가 결손 두 곳
 2행 (하악 궁): [Class II] [Class II Mod 1] [Class II Mod 2]
   - Class II: 한쪽(편측) 후방 결손, 반대쪽에는 구치까지 존재
   - Class II Mod 1: 편측 후방 결손 + 추가결손 한 곳
   - Class II Mod 2: 편측 후방 결손 + 추가결손 두 곳
 3행 (상악 궁): [Class III] [Class III Mod 1] [Class III Mod 4]
   - Class III: 편측 결손부 전·후방에 잔존치 있음
   - Class III Mod 1: 추가결손 한 곳
   - Class III Mod 4: 추가결손 네 곳 (※ 라벨은 "Mod 4"로 인쇄됨)
 4행: [Class IV] (상악 궁, 전치부 결손 — 정중선을 가로지르는 하나의 전방 결손부) / 나머지 2칸은 합쳐진 빈 칸에 글자 "No Modification"
(※ 각 일러스트 속 결손 치아의 정확한 개수는 일러스트의 해상도상 [?] — 라벨 외의 치아 개수 서술은 육안 개략임)

[왼쪽 단]
들에게는 반대로 생각되는 경우가 있어 혼동이 있을 수 있지만, 국소의치 설계의 원칙은 이를 논리적으로 구분할 수 있게 해준다. 이는 Class II 국소의치는 Class I과 Class III 두 가지 유형의 국소의치의 특성을 모두 포함하기 때문인데, 특히 치아지지를 받는 추가결손부가 존재할 때는 더욱 그렇다. 이 때문에 Kennedy는 Class II 편측성 후방연장형을 Class I 양측성 후방연장형과 Class III 치아지지형 사이에 위치시켰다. Class II 국소의치는 후방연장 조직지지형이기 때문에 Class I 국소의치와 유사하게 디자인되어야 한다. 그러나, Class II 부분무치악은 흔하게 치아지지(또는 Class III) 구성요소가 악궁에 존재하게 된다. Class II 국소의치는 Class I 국소의치와 Class III 국소의치의 설계형태를 모두 포함하고 있기 때문에 이들 사이에 분류하는 것이 적절하다. Kennedy 분류는 국소의치 설계의 원칙을 적용하기에 간단하며, 설계는 분류에 기초한다는 원칙에도 맞기 때문에 계속 사용되고 있다. 즉, 국소의치의 지지양상을 분류개념에 포함한 것이 Kennedy 분류체계인 것이다.

{B}III. Kennedy 분류에 추가적용되는 Applegate의 원칙{/B}
 Kennedy 분류만으로는 모든 경우에 적용하는데 문제점이 발견되어, O. C. Applegate가 추가적인 8가지 적용세칙을 보충함으로써 보다 널리 사용되게 되었다.
 {B}규칙 1.{/B} 주분류를 변경시킬 수 있는 어떠한 발치도 발치를 시행한 후 분류에 포함한다.
 {B}규칙 2.{/B} 제3대구치가 결손되고 회복시켜 주지 않는 경우에는 분류에 포함시키지 않는다.
 {B}규칙 3.{/B} 제3대구치가 존재해 있을 경우, 이것을 지대
(→ 오른쪽 단으로 이어짐)

[오른쪽 단]
(규칙 3 이어짐) 치로 사용할 때에만 분류에 포함시킨다.
 {B}규칙 4.{/B} 제2대구치가 결손되었어도 수복하지 않는다면 분류에 포함하지 않는다.
   (예. 대합되는 제2대구치도 결손되었고 회복시키지 않을 경우 등)
 {B}규칙 5.{/B} 하나 이상의 결손부위가 있을 때에는 최후방 결손부위(무치악부분)가 항상 주분류를 결정한다.
 {B}규칙 6.{/B} 주분류를 결정하고 남은 다른 결손부위는 modification(Mod)으로 표시하고, 그 수만 기록한다(그림 3-1).
 {B}규칙 7.{/B} Modification의 크기와 위치는 고려되지 않으며, 단지 수만을 표기한다.
 {B}규칙 8.{/B} Class IV에는 modification이 없다(그림 3-1).
   (정중선을 가로지르는 하나의 양측성 무치악부위의 후방에 다른 무치악부위가 있다면 이 부분이 주분류를 결정하게 된다 : 규칙 5).

[연두색 배경 박스]
{B}IV. Bailyn과 Skinner와 Kennedy 분류의 비교 예{/B}
 Bailyn 분류는 국소의치의 주 지지를 어디서 얻느냐에 따라 치아지지형을 Class I, 치조제 조직의 지지형을 Class II, 또는 이 두 가지 복합형(Class III)으로 단순분류한 것이다. Skinner 분류는 무치악조직의 지지능력과 지대치의 지지능력과의 관계에서 분류를 시도하였다. 즉, 국소의치의 기능적인 가치는 지지작용이 얼마나 좋은 상태인가에 따른 것으로, 자연치아인 지대치와 치조제 조직의 생물학적, 해부학적 상태에 따라 달라질 수 있다고 보는 것이다. 지대치와 무치악조직의 지지 정도에 따라 분류한 것이다(그림 3-2).
